## 01 · Vizitka

Načítaj meno, mesto a obľúbenú technológiu. Vypíš ich ako formátovanú textovú vizitku.

**Precvičíš:** `input`, premenné, f-string, `print`.

```text title="Príklad výstupu"
┌──────────────────────────┐
│ Meno: Lucia              │
│ Mesto: Bratislava        │
│ Technológia: Python      │
└──────────────────────────┘
```

:::tip[Nápoveda]
Rámik nemusí dynamicky meniť šírku. Začni s pevným formátom a až potom ho vylepši.
:::

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="vizitka.py"
name = input("Meno: ").strip()
city = input("Mesto: ").strip()
technology = input("Obľúbená technológia: ").strip()

rows = [
    f"Meno: {name}",
    f"Mesto: {city}",
    f"Technológia: {technology}",
]
width = max(len(row) for row in rows) + 2

print("┌" + "─" * width + "┐")
for row in rows:
    print(f"│ {row:<{width - 1}}│")
print("└" + "─" * width + "┘")
```

</details>

## 02 · Objednávka

Načítaj produkt, cenu za kus a počet kusov. Vypočítaj medzisúčet, 20 % DPH a celkovú cenu. Výsledky zobraz na dve desatinné miesta.

**Bonus:** pri aspoň piatich kusoch aplikuj 10 % zľavu pred výpočtom DPH.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="objednavka.py"
VAT_RATE = 0.20
DISCOUNT_RATE = 0.10
DISCOUNT_FROM_QUANTITY = 5

product = input("Produkt: ").strip()
unit_price = float(input("Cena za kus (€): "))
quantity = int(input("Počet kusov: "))

subtotal = unit_price * quantity
discount = subtotal * DISCOUNT_RATE if quantity >= DISCOUNT_FROM_QUANTITY else 0
price_after_discount = subtotal - discount
vat = price_after_discount * VAT_RATE
total = price_after_discount + vat

print(f"\n{quantity}× {product}")
print(f"Medzisúčet: {subtotal:.2f} €")
print(f"Zľava: {discount:.2f} €")
print(f"DPH: {vat:.2f} €")
print(f"Spolu: {total:.2f} €")
```

</details>

## 03 · Teplotný poradca

Načítaj teplotu a vypíš jednu z možností:

- pod `0`: mráz,
- od `0` do `14`: chladno,
- od `15` do `24`: príjemne,
- od `25`: teplo.

**Precvičíš:** `if`/`elif`/`else`, poradie hraníc.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="teplota.py"
temperature = float(input("Teplota (°C): "))

if temperature < 0:
    message = "Mrzne."
elif temperature < 15:
    message = "Je chladno."
elif temperature < 25:
    message = "Je príjemne."
else:
    message = "Je teplo."

print(message)
```

Keďže vetvy idú zdola ohraničenými intervalmi, druhá podmienka už nemusí kontrolovať `temperature >= 0`.

</details>

## 04 · Registrácia na workshop

Používateľ zadá vek a informáciu o súhlase zákonného zástupcu. Účasť je povolená od 18 rokov alebo od 15 rokov so súhlasom. Program má vysvetliť dôvod zamietnutia.

**Bonus:** pridaj kapacitu a stav otvorenia registrácie.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="registracia.py"
age = int(input("Vek: "))
answer = input("Súhlas zákonného zástupcu? (áno/nie): ")
has_guardian_consent = answer.strip().casefold() == "áno".casefold()

registration_open = True
free_places = 3

if not registration_open:
    print("Registrácia je zatvorená.")
elif free_places <= 0:
    print("Workshop je plný.")
elif age >= 18:
    print("Registrácia bola úspešná.")
elif age >= 15 and has_guardian_consent:
    print("Registrácia bola úspešná so súhlasom zástupcu.")
elif age >= 15:
    print("Neplnoletý účastník potrebuje súhlas zástupcu.")
else:
    print("Minimálny vek je 15 rokov.")
```

</details>

## 05 · Súčet až po sentinel

Opakovane načítavaj čísla. Hodnota `-1` ukončí vstup a do súčtu sa nezapočíta. Na konci vypíš počet hodnôt, súčet a priemer. Ošetri situáciu bez jedinej hodnoty.

**Precvičíš:** `while`, sentinel, akumulátor, delenie nulou.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="sucet.py"
total = 0.0
count = 0

while True:
    value = float(input("Číslo (-1 = koniec): "))
    if value == -1:
        break

    total += value
    count += 1

print(f"Počet hodnôt: {count}")
print(f"Súčet: {total:g}")

if count > 0:
    print(f"Priemer: {total / count:g}")
else:
    print("Priemer nemožno vypočítať — nebola zadaná žiadna hodnota.")
```

</details>

## 06 · Násobilka

Pomocou vnorených cyklov vypíš tabuľku násobenia od 1 do 10. Stĺpce zarovnaj.

```text title="Skrátený náhľad"

  2   4   6   8  10
  3   6   9  12  15
```

:::tip[Nápoveda]
Vo f-stringu môžeš zadať minimálnu šírku: `f"{value:>3}"`.
:::

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="nasobilka.py"
SIZE = 10

print("    ", end="")
for column in range(1, SIZE + 1):
    print(f"{column:>4}", end="")
print()
print("    " + "────" * SIZE)

for row in range(1, SIZE + 1):
    print(f"{row:>2} │", end="")
    for column in range(1, SIZE + 1):
        print(f"{row * column:>4}", end="")
    print()
```

## 07 · Kalkulačka ako funkcie

Vytvor samostatné funkcie `add`, `subtract`, `multiply` a `divide`. Hlavná časť programu načíta dve čísla a operáciu. Delenie nulou musí vrátiť zrozumiteľnú chybu.

**Bonus:** presuň funkcie do `calculator.py` a použi ich v `main.py`.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="calculator.py"
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    if b == 0:
        raise ValueError("Nulou nemožno deliť.")
    return a / b
```

```python title="main.py"
from calculator import add, divide, multiply, subtract

OPERATIONS = {
    "+": add,
    "-": subtract,
    "*": multiply,
    "/": divide,
}

first = float(input("Prvé číslo: "))
operator = input("Operácia (+, -, *, /): ").strip()
second = float(input("Druhé číslo: "))

operation = OPERATIONS.get(operator)

if operation is None:
    print("Neznáma operácia.")
else:
    try:
        print(f"Výsledok: {operation(first, second):g}")
    except ValueError as error:
        print(error)
```

</details>

## 08 · Analýza textového súboru

Načítaj cestu k `.txt` súboru a vypíš:

- počet riadkov,
- počet slov,
- počet neprázdnych znakov,
- najdlhší riadok.

Ošetri `FileNotFoundError` a súbor otvor s UTF-8.

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="analyza_suboru.py"
filename = input("Cesta k textovému súboru: ").strip()

try:
    with open(filename, "r", encoding="utf-8") as file:
        lines = file.readlines()

    word_count = sum(len(line.split()) for line in lines)
    character_count = sum(len("".join(line.split())) for line in lines)
    longest_line = max((line.rstrip("\n") for line in lines), key=len, default="")

    print(f"Riadky: {len(lines)}")
    print(f"Slová: {word_count}")
    print(f"Neprázdne znaky: {character_count}")
    print(f"Najdlhší riadok: {longest_line}")
except FileNotFoundError:
    print(f"Súbor {filename!r} neexistuje.")
except PermissionError:
    print("Súbor nemožno čítať — chýba oprávnenie.")
```

</details>

## 09 · Správa účastníkov

Vytvor zoznam slovníkov. Každý účastník má meno, e-mail a bodové skóre. Program vypíše priemer, najlepší výsledok a mená ľudí so skóre aspoň 75 %.

```python title="Štartovacie dáta"
participants = [
    {"name": "Eva", "email": "eva@example.com", "score": 92},
    {"name": "Marek", "email": "marek@example.com", "score": 64},
    {"name": "Zuzana", "email": "zuzana@example.com", "score": 81},
]
```

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="ucastnici.py"
participants = [
    {"name": "Eva", "email": "eva@example.com", "score": 92},
    {"name": "Marek", "email": "marek@example.com", "score": 64},
    {"name": "Zuzana", "email": "zuzana@example.com", "score": 81},
]

if participants:
    average = sum(person["score"] for person in participants) / len(participants)
    best = max(participants, key=lambda person: person["score"])
    successful = [person for person in participants if person["score"] >= 75]

    print(f"Priemer: {average:.1f} %")
    print(f"Najlepší výsledok: {best['name']} ({best['score']} %)")
    print("Úspešní účastníci:")
    for person in successful:
        print(f"- {person['name']} ({person['email']})")
else:
    print("Zoznam účastníkov je prázdny.")
```

</details>

## 10 · Mini projekt: denný tracker

Vytvor konzolový program, ktorý umožní:

1. pridať dokončenú úlohu,
2. zobraziť všetky úlohy,
3. filtrovať ich podľa kategórie,
4. uložiť ich do súboru a pri ďalšom spustení načítať.

Záznam reprezentuj slovníkom a záznamy drž v zozname. Na disk použi JSON, nie `pickle`, aby bol súbor čitateľný aj mimo Pythonu.

```python title="Navrhovaný tvar záznamu"
task = {
    "title": "Dokončiť Python cvičenie",
    "category": "study",
    "completed": True,
}
```

<details class="solution">
<summary>Zobraziť / skryť riešenie</summary>

```python title="tracker.py"
import json
from pathlib import Path

DATA_FILE = Path("tasks.json")


def load_tasks():
    try:
        with DATA_FILE.open("r", encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("Súbor s dátami je poškodený. Začínam s prázdnym zoznamom.")
        return []


def save_tasks(tasks):
    with DATA_FILE.open("w", encoding="utf-8") as file:
        json.dump(tasks, file, ensure_ascii=False, indent=2)


def add_task(tasks):
    title = input("Názov úlohy: ").strip()
    category = input("Kategória: ").strip().casefold()
    if title:
        tasks.append({"title": title, "category": category, "completed": True})
        save_tasks(tasks)
        print("Úloha bola uložená.")


def show_tasks(tasks, category=None):
    selected = [
        task for task in tasks
        if category is None or task["category"] == category
    ]
    if not selected:
        print("Nenašli sa žiadne úlohy.")
        return
    for position, task in enumerate(selected, start=1):
        print(f"{position}. {task['title']} [{task['category']}]")


tasks = load_tasks()

while True:
    print("\n1 — pridať | 2 — zobraziť | 3 — filtrovať | 0 — koniec")
    choice = input("Voľba: ").strip()

    if choice == "1":
        add_task(tasks)
    elif choice == "2":
        show_tasks(tasks)
    elif choice == "3":
        category = input("Kategória: ").strip().casefold()
        show_tasks(tasks, category)
    elif choice == "0":
        break
    else:
        print("Neznáma voľba.")
```

Riešenie ukladá súbor po každom pridaní. Pri väčšej aplikácii by sme oddelili používateľské rozhranie, dátový model a ukladaciu vrstvu.

</details>
