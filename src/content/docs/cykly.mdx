Cykly opakujú blok kódu bez toho, aby sme ten istý príkaz písali viackrát. Python má dva základné typy:

- `while` — opakuj, **kým** platí podmienka,
- `for` — prejdi **každý prvok** nejakej postupnosti.

## Cyklus `while`

`while` sa hodí, keď vopred nepoznáme počet opakovaní. Podmienka sa kontroluje pred každou iteráciou.

```python title="countdown.py"
seconds = 5

while seconds > 0:
    print(seconds)
    seconds -= 1

print("Štart!")
```

Premenná `seconds` sa musí meniť. Bez riadka `seconds -= 1` by podmienka zostala navždy pravdivá a vznikol by nekonečný cyklus.

:::tip[Ako zastaviť nekonečný program]
V termináli stlač `Ctrl+C`. Potom nájdi hodnotu, ktorá rozhoduje o ukončení, a over, či sa v každej potrebnej vetve naozaj mení.
:::

## Validácia vstupu

Cyklus vie používateľa opakovane vyzvať, kým nezadá platnú hodnotu.

```python title="validation.py"
age = int(input("Zadaj vek od 0 do 120: "))

while age < 0 or age > 120:
    print("Neplatná hodnota.")
    age = int(input("Zadaj vek od 0 do 120: "))

print(f"Uložený vek: {age}")
```

Tento príklad ešte nerieši text namiesto čísla — to pridáme v kapitole o výnimkách.

## Sentinel loop

**Sentinel** je špeciálna hodnota, ktorá znamená „koniec vstupu“. Nemala by sa dať pomýliť s platnou hodnotou.

```python title="average.py"
total = 0.0
count = 0

value = float(input("Suma objednávky (-1 = koniec): "))

while value != -1:
    total += value
    count += 1
    value = float(input("Suma objednávky (-1 = koniec): "))

if count > 0:
    print(f"Priemer: {total / count:.2f} €")
else:
    print("Nebola zadaná žiadna objednávka.")
```

Premenná `total` je **akumulátor** a `count` je **počítadlo**. Operátor `+=` je skrátený zápis pre `total = total + value`.

## Cyklus `for`

`for` sa hodí, keď prechádzame kolekciu alebo poznáme počet opakovaní.

```python
topics = ["premenné", "podmienky", "cykly"]

for topic in topics:
    print(f"Študujem: {topic}")
```

Premenná `topic` postupne dostane každú hodnotu zo zoznamu.

## `range()` bez hádania

`range(start, stop, step)` vytvorí postupnosť celých čísel. Hodnota `stop` sa **nezahŕňa**.

```python
for number in range(1, 6):
    print(number)  # 1, 2, 3, 4, 5

for even in range(0, 11, 2):
    print(even)    # 0, 2, 4, 6, 8, 10

for countdown in range(5, 0, -1):
    print(countdown)  # 5, 4, 3, 2, 1
```

| Zápis | Vygenerované hodnoty |
| --- | --- |
| `range(5)` | `0, 1, 2, 3, 4` |
| `range(2, 5)` | `2, 3, 4` |
| `range(2, 10, 3)` | `2, 5, 8` |
| `range(3, 0, -1)` | `3, 2, 1` |

## Vnorené cykly

Vnútorný cyklus sa dokončí pri každej jednej iterácii vonkajšieho cyklu. Takto vieme spracovať tabuľku, maticu alebo kombinácie hodnôt.

```python title="schedule.py"
for day in range(1, 4):
    print(f"Deň {day}")

    for lesson in range(1, 3):
        print(f"  Lekcia {lesson}")
```

Výsledkom je šesť lekcií: dve pre každý z troch dní.

## Kompletný príklad: tri objednávky

```python title="orders.py" {7-8}
grand_total = 0.0

for order_number in range(1, 4):
    print(f"\nObjednávka {order_number}")
    item_count = int(input("Počet položiek: "))
    order_total = 0.0

    for item_number in range(1, item_count + 1):
        price = float(input(f"Cena položky {item_number}: "))
        order_total += price

    grand_total += order_total
    print(f"Suma objednávky: {order_total:.2f} €")

print(f"\nCelkový obrat: {grand_total:.2f} €")
```

## Ako vybrať správny cyklus

| Situácia | Voľba |
| --- | --- |
| „Opakuj päťkrát“ | `for` + `range(5)` |
| „Pre každý produkt v zozname“ | `for` |
| „Kým používateľ nezadá správnu hodnotu“ | `while` |
| „Čítaj hodnoty až po slovo `koniec`“ | `while` so sentinelom |

## Zapamätaj si

- Iterácia je jedno vykonanie tela cyklu.
- `range()` nezahŕňa koncovú hodnotu.
- Každý `while` musí mať realistickú cestu k ukončeniu.
- Pri vnorení sa vnútorný cyklus vykoná celý pre každú iteráciu vonkajšieho.
