## Priebeh kurzu

1. **Deň 1** — odkiaľ sa vzali kontajnery, obraz vs. kontajner, kontajner vs. virtuálny stroj. Prvé kontajnery: `run`, `ls`, `stop`, `logs`, `attach`, `rm`, `--rm`, `-d`, `-it`. Konfigurácia cez premenné prostredia a `.env` súbor, publikovanie portov, `inspect` a stavy kontajnera.
2. **Deň 2** — perzistencia dát: anonymné a pomenované zväzky, bind mounty, používateľ v kontajneri. Prepojenie kontajnerov (MySQL + Adminer) a **Docker Compose** (WordPress).
3. **Deň 3** — reštartovacie politiky a vlastné obrazy: `Dockerfile`, vrstvy a cache, push do registra (`ttl.sh`). Balenie vlastnej Python aplikácie podľa best practices: linter, správny základný obraz, multi-stage build, skenovanie zraniteľností, používateľ bez root práv, healthcheck.
4. **Deň 4** — aliasy, Docker kontexty, obmedzenie zdrojov. Nástroje na správu (dry, Portainer), vlastný register, Traefik, Watchtower.

:::tip[Dlhá syntax]
> „Ja ako učiteľ vám budem ukazovať tento explicitný zápis. A vy ako ľudia z praxe si kľudne komplikujte život krátkym zápisom.“

V poznámkach je preto všade `docker container run`, `docker container ls`, `docker image ls` namiesto `docker run`, `docker ps`, `docker images`. Prečo, je v kapitole [Prvé kontajnery](/devops-notes/docker/prve-kontajnery/).
:::
