Kurz **Docker 101 + 202** (štyri dni) vedie Mirek. Poznámky vznikli z prepisu záznamu všetkých štyroch dní, slajdov a materiálov s labákmi. Sú usporiadané podľa tém, opravené a doplnené o otázky a cvičenia. Témy zo slajdov, ktoré sa na kurze nebrali (napr. Lab Matrix, `:Z` pre SELinux, ukážky s Podmanom), v poznámkach nie sú.

:::note[Čo v poznámkach zámerne chýba]
API kľúč OpenWeatherMap, heslo a IP adresy laboratórnych strojov sú nahradené zástupnými textami (`<API_KEY>`, `<IP>`). Mená účastníkov sú vynechané (kontext `riso` je v poznámkach `kolega`). Postup na smerovanie cez firemnú VPN (`route add`) je firemne špecifický a vynechaný. Prihlasovacie údaje v labákoch (`admin`/`secret123`, `batman`/`catwoman`) sú cvičné.
:::

:::caution[Príkazy neboli spustené]
Pri písaní poznámok nebol k dispozícii Docker, takže príkazy neboli spustené ako pri kurze Git. Správanie je overené voči dokumentácii Dockera a záznamu z kurzu.
:::

## Opravy

- **Slajdy, deň 2:** `docker image inspect --format "{{ .ContainerConfig.Volumes }}"` — pri obraze je to `.Config.Volumes` (na kurze `ContainerConfig` vrátil chybu).
- **Slajdy, deň 3:** `docker image run ttl.sh/…` — správne `docker container run`.
- **Materiály, deň 3:** vo finálnom Dockerfile builder vytvára `/venv`, ale main stage kopíruje `/app/venv` — cesty musia sedieť.
- **Materiály, deň 4:** alias obsahuje `$(id--user)` — správne `$(id --user)`.
- **Prednáška:** úvodzovky v `.env` — `docker container run --env-file` ich neodstraňuje, stanú sa súčasťou hodnoty.
- **Prednáška:** `curl -f` pri HTTP chybe vracia exit kód 22 (nie „päťdesiat-niečo“); healthcheck berie iba 0 a 1, preto `|| exit 1`.
- **Prednáška:** v slim obraze nie je `curl`, healthcheck s ním je hneď `unhealthy` — v poznámkach je kontrola cez Python.
- **Prednáška:** `docker volume prune` v novších verziách maže predvolene iba anonymné zväzky (pomenované s `--all`).
- **Prednáška:** WordPress `fpm-alpine` sa nenačítal — varianty `fpm` nemajú webový server.
- **Prednáška:** Docker kontext cez `ssh://ubuntu@IP` zlyhal na kľúči — treba záznam v `~/.ssh/config` s `IdentityFile`.
