The **Docker 101 + 202** course (four days) is taught by Mirek. The notes are based on transcripts of all four days, the slides, and the lab material. They are organised by topic, corrected, and extended with questions and exercises. Topics from the slides that weren't covered in class (e.g. Lab Matrix, `:Z` for SELinux, the Podman examples) are left out.

:::note[What is deliberately left out]
The OpenWeatherMap API key and the lab machines' password and IP addresses are replaced with placeholders (`<API_KEY>`, `<IP>`). Participants' names are omitted (the `riso` context is `colleague` in the notes). The procedure for routing around the company VPN (`route add`) is company-specific and left out. Credentials in the labs (`admin`/`secret123`, `batman`/`catwoman`) are practice values.
:::

:::caution[The commands were not run]
Docker wasn't available while these notes were written, so the commands were not run as they were for the Git course. Behaviour was checked against the Docker documentation and the course recording.
:::

## Corrections

- **Slides, day 2:** `docker image inspect --format "{{ .ContainerConfig.Volumes }}"` — for an image it's `.Config.Volumes` (in class `ContainerConfig` returned an error).
- **Slides, day 3:** `docker image run ttl.sh/…` — correct is `docker container run`.
- **Material, day 3:** in the final Dockerfile the builder creates `/venv` but the main stage copies `/app/venv` — the paths must match.
- **Material, day 4:** the alias contains `$(id--user)` — correct is `$(id --user)`.
- **Lecture:** quotes in `.env` — `docker container run --env-file` doesn't strip them; they become part of the value.
- **Lecture:** `curl -f` exits with code 22 on an HTTP error (not "fifty-something"); a healthcheck understands only 0 and 1, hence `|| exit 1`.
- **Lecture:** the slim image has no `curl`, so a healthcheck using it is `unhealthy` right away — the notes check with Python.
- **Lecture:** in newer versions `docker volume prune` removes only anonymous volumes by default (named ones with `--all`).
- **Lecture:** WordPress `fpm-alpine` didn't load — the `fpm` variants have no web server.
- **Lecture:** a Docker context via `ssh://ubuntu@IP` failed on the key — it needs an entry in `~/.ssh/config` with `IdentityFile`.
