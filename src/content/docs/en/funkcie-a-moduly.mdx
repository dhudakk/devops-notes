A function is a named block of code with one clear job. Splitting a large problem into smaller parts improves readability, testing, and reuse.

```python
def print_header():
    print("=" * 30)
    print("      PYTHON WORKSHOP")
    print("=" * 30)


print_header()
```

PEP 8 style recommends two blank lines between top-level function definitions and the rest of the program.

## Parameters and arguments

A **parameter** is a name in a function definition. An **argument** is the concrete value supplied in a call.

```python
def greet(name, language="en"):
    if language == "sk":
        return f"Ahoj, {name}!"
    return f"Hello, {name}!"


print(greet("Maria"))                  # positional argument
print(greet("Ján", language="sk"))   # keyword argument
```

A parameter with a default value must follow parameters without defaults.

## Return values

`return` passes a result to the caller and immediately ends the function.

```python
def total_price(unit_price, quantity, discount=0.0):
    subtotal = unit_price * quantity
    return subtotal * (1 - discount)


price = total_price(49.90, 3, discount=0.10)
print(f"Total: €{price:.2f}")
```

A function without an explicit `return` returns `None`. It is sometimes informally called a “void function,” but technically it still returns a value.

```python
def show_status(message):
    print(f"Status: {message}")


result = show_status("done")
print(result)  # None
```

## Small functions for decisions

A Boolean function names a rule and returns `True` or `False`.

```python
def is_valid_age(age):
    return 0 <= age <= 120


if is_valid_age(28):
    print("The age is valid")
```

A function can return multiple values. Python packages them into a tuple.

```python
def convert_minutes(total_minutes):
    hours = total_minutes // 60
    minutes = total_minutes % 60
    return hours, minutes


hours, minutes = convert_minutes(135)
print(f"{hours} h {minutes} min")
```

## Local and global scope

A variable created inside a function is normally **local** — it does not exist outside that function. Functions can read globals, but modifying global state makes testing more difficult.

```python
VAT_RATE = 0.20  # A global constant is reasonable.


def price_with_vat(net_price):
    gross_price = net_price * (1 + VAT_RATE)  # local variable
    return gross_price
```

:::caution[Use `global` sparingly]
You do not need `global` to read a global value. It is required only when rebinding one inside a function — which is often a sign that the program design can be improved.
:::

## Standard-library modules

A module is a Python file containing functions, classes, or constants. `import` makes its public names available.

```python title="random_demo.py"
import math
import random

radius = 3
area = math.pi * radius**2
roll = random.randint(1, 6)

print(f"Circle area: {area:.2f}")
print(f"Die roll: {roll}")
```

`math` and `random` are part of the standard library. Packages such as NumPy, pandas, and Beautiful Soup are installed separately, usually with `pip`.

```bash title="Terminal"
python -m pip install pandas
```

## Your own module

Functions can live in a separate `.py` file and be imported elsewhere.

```python title="helpers.py"
def format_price(value):
    return f"€{value:.2f}"


def calculate_discount(price, percent):
    return price * percent / 100
```

```python title="main.py"
from helpers import calculate_discount, format_price

price = 120.0
discount = calculate_discount(price, 15)

print(format_price(price - discount))
```

For this simple example, `helpers.py` and `main.py` must be in the same folder.

## Complete example: registration module

```python title="registration.py"
MINIMUM_AGE = 15


def can_register(age, has_guardian_consent):
    if age >= 18:
        return True
    return age >= MINIMUM_AGE and has_guardian_consent


def registration_message(name, allowed):
    if allowed:
        return f"{name}: registration successful"
    return f"{name}: registration denied"


name = input("Name: ").strip()
age = int(input("Age: "))
answer = input("Guardian consent? (yes/no): ").strip().lower()

allowed = can_register(age, answer == "yes")
print(registration_message(name, allowed))
```

## Remember

- A function should have one clear responsibility.
- Parameters belong in definitions; arguments belong in calls.
- `return` gives a result back; `print()` only displays it.
- Limit global state and name constants in uppercase.
- A module is a `.py` file; a package organizes multiple modules.
