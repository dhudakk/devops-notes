## Course outline

1. **Day 1** — what version control is, installing Git and `git config`, working locally: `init`, `status`, `add`, `commit`, `diff`, `log`, `show`, `rm`, `mv`, `.gitignore`, undoing changes (`restore`, `revert`, `reset`). In the afternoon: the GitHub/GitLab web interface, SSH keys, `clone`, and `push`.
2. **Day 2** — branches (`checkout -b`, `switch`), `merge` and resolving conflicts, working through a remote (`fetch`, `pull`, a rejected push, simulating a colleague with a second clone), `stash`, tags, `rebase`, and detached HEAD.

:::tip[Five commands for every day]
> "For real work you only need a handful of commands."

`git status` → `git add` → `git commit -m "…"` → `git push`, and `git pull` before you start. You can always look the rest up — what matters is understanding what they do.
:::
