## Course outline

1. **Day 1** — horizontal and vertical scaling, orchestration, cluster architecture, and the K3s distribution. Pods (`run`, `logs`, `exec`, `describe`, `port-forward`), deployments and ReplicaSets, scaling. ClusterIP, NodePort, and LoadBalancer services, labels and selectors, rolling updates.
2. **Day 2** — namespaces and contexts, Krew plugins. Imperative and declarative approaches, generating manifests (`--dry-run=client -o yaml`), WordPress as a manifest, session affinity. CPU and memory requests and limits, throttling and OOM kill, k9s.
3. **Day 3** — the Horizontal Pod Autoscaler (HPA), selective updates by label. ConfigMaps and Secrets, Ingress and the Ingress Controller (Traefik), path-based and host-based rules, the Gateway API.
4. **Day 4** — persistence: `emptyDir`, `hostPath`, PersistentVolume, PersistentVolumeClaim, and StorageClass, CSI drivers. A brief look at jobs, DaemonSets, StatefulSets, and Kubernetes distributions.

:::tip[The `k` alias]
The lab machines had an alias `k` for `kubectl`. The notes always use the full `kubectl` so the commands can be copied anywhere. If you want the shortcut at home: `alias k=kubectl`.
:::
