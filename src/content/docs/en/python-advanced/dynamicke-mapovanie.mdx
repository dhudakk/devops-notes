<KeyPoints>
- **Dynamic Task Mapping** creates **N instances of the same task at run time** — one per item of the input list. You do not need to know how many there will be when you write the DAG.
- `.expand(arg=list)` — the task “multiplies” by this argument; `.partial(arg=value)` — arguments that are the same for every instance.
- DAG input parameters with a type, title, and description: `@dag(params={"query": Param(default=[], type="array", ...)})` — they appear in the **Trigger** form.
- You reach a run's parameters only **inside a task**, through the context: `get_current_context()["params"]["query"]`.
- Pass a mapped task's result on through `.expand(...)` again — each instance processes its own item.
</KeyPoints>

## The problem

We want weather for **several places**, not one. We can store several values in the `weather_city` Variable (one city per line), but how do we make sure the data for each city is downloaded and processed **separately**?

The answer is **Dynamic Task Mapping**. Instead of deciding how many tasks you need when writing the DAG, Airflow finds out at run time — from the length of a list.

## DAG input parameters: Param

So far a DAG parameter had only a type and a default value. The **`Param`** type adds more properties — they are used in the form for a manual run (the **Trigger** button):

```python
from airflow.sdk import Param

@dag(
    ...,
    params={
        "query": Param(
            default=[],
            type="array",
            title="Locations",
            description="List of locations. One location per line.",
        ),
    },
)
def main():
    ...
```

`type="array"` means a list — the form takes one item per line. The types and validation are the same as in [JSON Schema](/devops-notes/en/python-advanced/validacia-dat/) (`string`, `integer`, `array`, `minimum`…).

## The run context

How do you get at the parameter's value? The `main()` function runs when the DAG is **parsed**, not when it runs — at that point no run exists yet. The value is available only in the **context**: a dictionary Airflow prepares for every run. It holds metadata about the run — when it runs, which parameters it got, which DAG it is, and so on. You get the context **only inside a task**, through `get_current_context()`.

A helper task `get_locations()` returns the list of places:

- if the DAG input is empty, it uses the `weather_city` Variable (one city per line),
- otherwise it returns the given input.

```python
from airflow.sdk import Variable, get_current_context, task


@task(task_display_name="Get Locations")
def get_locations() -> list[str]:
    context = get_current_context()
    locations = context["params"]["query"]
    if not locations:
        locations = Variable.get("weather_city", default="kosice,sk").splitlines()
    return locations
```

`.splitlines()` splits the Variable's multi-line value into a list. Scheduled runs have no input, so they use the Variable.

## .expand() and .partial()

| Method | Meaning |
| --- | --- |
| `.expand(arg=list)` | the argument the task is dynamically multiplied by — one instance per item |
| `.partial(arg=value)` | arguments that are the same for every instance |

```python
def main():
    locations = get_locations()
    data = tg_healthcheck() >> scrape_data.expand(query=locations)
    valid_data = validate_data.expand(payload=data)
    entries = process_data.expand(data=valid_data)
    publish_data.expand(entry=entries)
```

- `scrape_data.expand(query=locations)` → 3 instances of `scrape_data` for 3 cities.
- `validate_data.expand(payload=data)` → a mapped task's result is a list again, so validation also runs for each city separately. The same goes for processing and publishing.
- When you pass a mapped task's result to a **non-mapped** task (`summary(data)`), it receives a **list** of all the results at once.

An example with `.partial()` — the same units for every city:

```python
results = greet.partial(units="metric").expand(city=["kosice,sk", "presov,sk", "praha,cz"])
# greet(city="kosice,sk", units="metric"), greet(city="presov,sk", units="metric"), …
```

If you run the DAG now:

- with a list of places filled in the Trigger form → those are used,
- without input (including scheduled runs) → the cities from the Variable are used.

## One file per city

If all `publish_data` instances appended to one `dataset.csv` in S3 at once, they would overwrite each other's writes (download → append → upload is not atomic). So each city gets **its own file** — we build the name from the CSV line:

```python
_, name, country, *_ = entry.split(",")      # "2026-…,Kosice,SK,15.8,…"
key = f"{name}-{country}.csv".lower()        # "kosice-sk.csv"
```

The whole task is in the project below.

## The Weather Ingestion group

You can also group downloading, validation, processing, and publishing into a [task group](/devops-notes/en/python-advanced/healthcheck/#task-groups):

```python
@task_group(
    "weather_ingestion",
    group_display_name="Weather Ingestion",
    tooltip="Retrieve, process and upload weather info.",
)
def weather_ingestion():
    locations = get_locations()
    data = scrape_data.expand(query=locations)
    valid_data = validate_data.expand(payload=data)
    entries = process_data.expand(data=valid_data)
    publish_data.expand(entry=entries)
    return data


@dag(...)
def main():
    tg_healthcheck() >> weather_ingestion()
```

from pathlib import Path

# ~/airflow — derived from this file's location, so it works wherever Airflow lives
AIRFLOW_HOME = Path(__file__).parent.parent
DATA_PATH = AIRFLOW_HOME / "data"
SCHEMA_PATH = DATA_PATH / "openweathermap.schema.json"

# Airflow Connection IDs
OPENWEATHERMAP_CONN = "openweathermap"
STORAGE_CONN = "rustfs"

DATASET_BUCKET = "datasets"
CSV_HEADER = "dt,name,country,temp,humidity,pressure,wind_speed,wind_deg"

```python title="dags/tasks.py"
"""Tasks shared by several DAGs."""

import logging
from datetime import timedelta
from http import HTTPStatus

import httpx
from airflow.sdk import BaseHook, task, task_group
from airflow.sdk.exceptions import AirflowException

from constants import OPENWEATHERMAP_CONN, STORAGE_CONN

logger = logging.getLogger(__name__)


@task.bash(task_display_name="Ping OpenWeatherMap")
def is_service_alive_in_bash() -> str:
    conn = BaseHook.get_connection(OPENWEATHERMAP_CONN)
    return f"ping -c 1 -w 2 {conn.host}"


@task(
    task_display_name="OpenWeatherMap Healthcheck",
    retries=3,
    retry_delay=timedelta(seconds=30),
)
def is_service_alive() -> None:
    conn = BaseHook.get_connection(OPENWEATHERMAP_CONN)
    url = f"{conn.schema}://{conn.host}:{conn.port}"
    response = httpx.head(url, follow_redirects=True, timeout=10)
    if response.status_code != HTTPStatus.OK:
        raise AirflowException(f"OpenWeatherMap unavailable: {response.status_code}")


@task(task_display_name="RustFS Healthcheck", retries=3, retry_delay=timedelta(seconds=30))
def is_rustfs_alive() -> None:
    logger.info("RustFS Healthcheck")
    conn = BaseHook.get_connection(STORAGE_CONN)
    response = httpx.get(f"{conn.schema}://{conn.host}:{conn.port}/health", timeout=10)
    if response.status_code != HTTPStatus.OK:
        raise AirflowException(f"RustFS is unhealthy: {response.status_code}")


@task_group(
    group_id="tg_healthcheck",
    group_display_name="Healthcheck",
    tooltip="Healthcheck of external services.",
)
def tg_healthcheck():
    return [is_service_alive_in_bash(), is_service_alive(), is_rustfs_alive()]
```

```python title="dags/weather_scraper.py"
"""Weather scraper: healthchecks -> scrape -> validate -> process -> publish to S3."""

import json
import logging
import os
from http import HTTPStatus
from pathlib import Path
from tempfile import mkstemp

import boto3
import httpx
import jsonschema
from airflow.sdk import BaseHook, Param, Variable, dag, get_current_context, task
from airflow.sdk.exceptions import AirflowFailException
from botocore.exceptions import ClientError
from pendulum import datetime, from_timestamp

from constants import (
    CSV_HEADER,
    DATASET_BUCKET,
    OPENWEATHERMAP_CONN,
    SCHEMA_PATH,
    STORAGE_CONN,
)
from tasks import tg_healthcheck

logger = logging.getLogger(__name__)


@task(task_display_name="Get Locations")
def get_locations() -> list[str]:
    """Cities from the Trigger form, otherwise from the weather_city Variable."""
    context = get_current_context()
    locations = context["params"]["query"]
    if not locations:
        locations = Variable.get("weather_city", default="kosice,sk").splitlines()
    logger.info("Locations: %s", locations)
    return locations


@task(task_display_name="Scrape Data")
def scrape_data(query: str) -> dict:
    logger.info("Scraping data for %s", query)
    conn = BaseHook.get_connection(OPENWEATHERMAP_CONN)
    url = f"{conn.schema}://{conn.host}:{conn.port}/data/2.5/weather"
    params = {
        "q": query,
        "appid": conn.password,
        "units": conn.extra_dejson.get("units", "metric"),
    }
    response = httpx.get(url, params=params, timeout=10)
    if response.status_code != HTTPStatus.OK:
        logger.warning("OpenWeatherMap answered %s for %s", response.status_code, query)
        raise AirflowFailException(f"Cannot get weather for {query}: {response.status_code}")
    return response.json()


@task(task_display_name="Validate Data")
def validate_data(payload: dict) -> dict:
    schema = json.loads(SCHEMA_PATH.read_text(encoding="utf-8"))
    try:
        jsonschema.validate(instance=payload, schema=schema)
    except jsonschema.ValidationError as error:
        logger.error("Unexpected data from the service: %s", error.message)
        raise AirflowFailException("The data does not match the schema.") from error
    return payload


@task(task_display_name="Process Data")
def process_data(data: dict) -> str:
    values = [
        from_timestamp(data["dt"]).to_iso8601_string(),
        data["name"],
        data["sys"]["country"],
        data["main"]["temp"],
        data["main"]["humidity"],
        data["main"]["pressure"],
        data["wind"]["speed"],
        data["wind"]["deg"],
    ]
    return ",".join(str(value) for value in values)


@task(task_display_name="Publish Data")
def publish_data(entry: str) -> None:
    """Append the line to <city>-<country>.csv in the S3 bucket."""
    conn = BaseHook.get_connection(STORAGE_CONN)
    storage = boto3.resource(
        "s3",
        endpoint_url=f"{conn.schema}://{conn.host}:{conn.port}",
        aws_access_key_id=conn.login,
        aws_secret_access_key=conn.password,
    )
    bucket = storage.Bucket(DATASET_BUCKET)

    _, name, country, *_ = entry.split(",")
    key = f"{name}-{country}.csv".lower()

    fd, temp_name = mkstemp(prefix="weather-", suffix=".csv")
    os.close(fd)  # mkstemp returns an open file descriptor — close it
    path = Path(temp_name)
    try:
        try:
            bucket.download_file(key, str(path))
        except ClientError:
            logger.warning("%s does not exist yet. First upload.", key)
            path.write_text(CSV_HEADER + "\n", encoding="utf-8")
        with path.open("a", encoding="utf-8") as file:
            print(entry, file=file)
        bucket.upload_file(str(path), key)
        logger.info("Uploaded %s to bucket %s", key, DATASET_BUCKET)
    finally:
        path.unlink(missing_ok=True)


@dag(
    "weather_scraper",
    dag_display_name="Weather Scraper",
    description="Scrapes weather from openweathermap.org",
    schedule="*/20 * * * *",
    start_date=datetime(2026, 1, 1),
    tags=["weather", "devops"],
    catchup=False,
    params={
        "query": Param(
            default=[],
            type="array",
            title="Locations",
            description="List of locations. One location per line.",
        ),
    },
)
def main():
    locations = get_locations()
    data = tg_healthcheck() >> scrape_data.expand(query=locations)
    valid_data = validate_data.expand(payload=data)
    entries = process_data.expand(data=valid_data)
    publish_data.expand(entry=entries)


if __name__ == "__main__":
    main().test()
else:
    main()
```

Differences from the slides: the healthchecks raise `AirflowException` (not `AirflowFailException`) so that `retries` apply; the temporary file is closed and deleted in `finally`; validation has been added.

**How it was tested** (Airflow 3.3.2, `dag.test()`): a local stand-in for OpenWeatherMap, S3 through [moto](https://github.com/getmoto/moto) (a local AWS stand-in). Three runs:

1. no input → cities from the Variable (`kosice,sk`, `bratislava,sk`) → `kosice-sk.csv` and `bratislava-sk.csv` were created with a header,
2. input `["presov,sk", "kosice,sk"]` → a new `presov-sk.csv`, and a line added to `kosice-sk.csv`,
3. input `["poprad,sk", "nowhere"]` → the instance for `nowhere` failed on 404 (`AirflowFailException`), and the run is `failed`.

## Exercises

### 17.1 · Cities without duplicates

Change `get_locations()` to drop empty lines and spaces around names, lower-case the names, and remove duplicates (keeping the order).

<Solution>
```python
@task(task_display_name="Get Locations")
def get_locations() -> list[str]:
    context = get_current_context()
    locations = context["params"]["query"]
    if not locations:
        locations = Variable.get("weather_city", default="kosice,sk").splitlines()
    cleaned = (location.strip().lower() for location in locations)
    return list(dict.fromkeys(location for location in cleaned if location))
```

`dict.fromkeys()` keeps the order of first occurrence and drops duplicates (dictionary keys are unique).
</Solution>
