## Course project

Throughout the course we build one workflow:

```text
[ Scrape Data ] -- json --> [ Process Data ] -- csv --> [ Publish Data ]
```

1. **Day 1** — the workflow as a Python script split into three functions: functions, HTTP, JSON, CSV, and exceptions.
2. **Day 2** — the script becomes a command-line tool (click); then Apache Airflow: installation, the first DAG, tasks and XCom, Connections and Variables, data validation, a healthcheck, and retries.
3. **Next** — more tasks and more of Airflow on top of the same workflow.
