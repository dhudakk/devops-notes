## httpie instead of curl

`http` (the **httpie** package) is a command-line HTTP client written in Python. Compared with `curl`:

- you write query parameters separately with `==` instead of assembling the whole URL,
- it formats and colours JSON responses automatically and shows the headers too.

```bash
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric
```

## Never process JSON with grep

> “Forget about pulling it out with grep. The biggest nonsense you could do.”

**jq** is the tool for JSON. You will meet JSON all the time — with HTTP, when chaining web services — because it is machine-readable and easy to send around.

```bash
jq .main.temp weather.json
jq -r '[.dt, .name, .main.temp] | @csv' weather.json
```

## Unix: the best interface between processes is stdin/stdout

One of the Unix design principles: small tools that read standard input and write standard output can be chained with `|`. Do not write intermediate results to files when you can pipe them.

```bash
scrape_data | process_data | publish_data
```

## tee instead of >>

`tee -a file` appends output to a file **and** shows it on screen — you see what is being written. Remove duplicate lines with e.g. `sort -u` (or `sort | uniq`).

## crontab is legacy

New systems often do not even install `crontab` any more — **systemd timers** replace it (`systemctl list-timers`). And a CI/CD pipeline is scheduled task execution too, only the trigger is an event (a commit, a push), not time.

## Swap and zram when RAM runs out

On a machine with 4 GB of RAM, Airflow easily runs out of memory — the machine freezes and SSH drops. A quick fix is a **2 GB swap file** (`fallocate`, `mkswap`, `swapon`, `free -h`). Mirek also wants to try **zram**: the kernel compresses part of the RAM on the fly, so 4 GB effectively becomes more, at a small performance cost. On his old 1 GB Raspberry Pis it “can help quite elegantly”.

## Airflow as a systemd service

Mirek's experiment on day 3: running Airflow as a **systemd unit** instead of in tmux. What appeals to him most is `KillMode=control-group` — on stop, systemd kills everything the service started, and `Restart=on-failure` restarts it by itself after a crash. “I haven't done this before, but I see potential in it.” The steps are in [Installing Airflow](/devops-notes/en/python-advanced/airflow-instalacia/#a-systemd-service).

## Swap disappears after a reboot

On day 3 Mirek's machine froze again — after a reboot his swap was zero. `swapon` lasts only until a reboot; to enable it permanently, add a line to `/etc/fstab`:

```text
/swapfile none swap sw 0 0
```

## sh — commands as Python functions

There is `os.system`, `subprocess`… for running commands from Python, but the **sh** module is “extremely user friendly”: `from sh import ping` and `ping("-c", 1, host)`. It has perks like `_timeout=3`. “When you work with the shell and don't need anything massive, this module is just great.” More in [Healthcheck](/devops-notes/en/python-advanced/healthcheck/#way-2-the-sh-module).

## Let a JSON Schema be generated

You do not need to write a schema from scratch:

- [jsonschemavalidator.net](https://www.jsonschemavalidator.net/) — schema on the left, document on the right, errors show up immediately,
- online generators (*JSON schema from document*) build a skeleton from a sample JSON,
- Claude or ChatGPT also add ranges and descriptions — just say it is a response from openweathermap.org.

## mktemp for temporary files

Bash scripts sometimes need a temporary file too. Do not make up a name — `mktemp` creates a file with a unique name in `/tmp` (`-d` a directory, `-u` only prints a name). The Python equivalent is `tempfile.mkstemp()`.
