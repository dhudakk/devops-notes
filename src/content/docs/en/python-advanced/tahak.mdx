## Bash workflow: httpie + jq

<div class="sheet-grid">

```bash title="HTTP from the terminal"
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric

curl "https://api.openweathermap.org/data/2.5/weather?q=kosice,sk&appid=$APPID&units=metric"
```

```bash title="jq"
jq .                    # whole JSON, pretty
jq .main.temp           # nested key
jq '.dt, .name'         # several values
jq -r '[.dt, .name] | @csv'
jq -r '.dt | todate'    # timestamp → ISO
... | tee -a dataset.csv  # append + print
```

## Apache Airflow

<div class="sheet-grid">

```bash title="Install and run"
pip install apache-airflow
airflow info                # creates ~/airflow/airflow.cfg
export AIRFLOW_HOME=$(pwd)/airflow_home
airflow standalone          # everything at once, UI :8080
tmux attach                 # back to the session
sudo systemctl status airflow
```

```bash title="CLI"
airflow dags list
airflow tasks list weather_scraper
airflow dags test weather_scraper
airflow dags trigger -l 2026-03-15 weather_scraper
airflow variables set weather_city poprad,sk
airflow variables get weather_city
airflow connections get openweathermap
```

```python title="DAG and tasks"
from airflow.sdk import dag, task
from pendulum import datetime

@task
def scrape_data(query: str) -> dict: ...

@dag("weather_scraper", schedule="*/20 * * * *",
     start_date=datetime(2026, 1, 1),
     catchup=False, tags=["weather"])
def main(query: str = "kosice,sk"):
    data = scrape_data(query)
    is_service_alive() >> data

if __name__ == "__main__":
    main().test()
else:
    main()
```

```python title="Connections, Variables, errors"
from airflow.sdk import BaseHook, Variable
from airflow.sdk.exceptions import (
    AirflowException, AirflowFailException)

conn = BaseHook.get_connection("openweathermap")
conn.host; conn.port; conn.password
conn.extra_dejson.get("units")
Variable.get("weather_city", default="kosice,sk")
Variable.get("cfg", deserialize_json=True)

@task(retries=3, retry_delay=timedelta(seconds=30))
raise AirflowException("retry me")
raise AirflowFailException("no retry")
```

</div>

| What | How |
| --- | --- |
| cron | `min hour day month weekday` · `*/20 * * * *` · `@hourly`, `@daily`, `@weekly`, `@monthly`, `@yearly` |
| config via environment | `AIRFLOW__CORE__LOAD_EXAMPLES=False` |
| Variable / Connection from environment | `AIRFLOW_VAR_WEATHER_CITY=…` · `AIRFLOW_CONN_OPENWEATHERMAP='{"conn_type": …}'` |
| task states | queued (grey) · running · success (green) · failed (red) · upstream_failed (orange) · up_for_retry (yellow) |
| `retries=3` | up to 4 runs; `retry_delay` defaults to 300 s |
| a file next to the DAG | `Path(__file__).parent / "weather.schema.json"` |
| JSON schema | `jsonschema.validate(instance=data, schema=schema)` |
| logging | `logger = logging.getLogger(__name__)` · DEBUG < INFO < WARNING < ERROR < CRITICAL |
| swap | `fallocate -l 2G /swapfile` → `chmod 600` → `mkswap` → `swapon` · `free -h` |
| tmux (prefix `Ctrl+b`) | `c` new window · `n`/`p` next/previous · `"`/`%` split · `d` detach · `tmux attach` |

## Handy bits

| What | How |
| --- | --- |
| type of a variable | `type(var)` |
| info about a variable in ipython | `var?` |
| HTTP status codes | `2xx` OK · `3xx` redirect · `4xx` client error · `5xx` server error |
| exit status in Bash | `echo $?` — `0` OK, anything else an error |
| length of a string / list | `len(var)` |
| building strings | f-string: `f"{url}?q={query}"` |
| key neither in code nor in arguments | `APPID=... ./workflow.py kosice` |
