The **Python for DevOps with Apache Airflow** course is taught by Mirek. The notes are based on the slides and on a transcript of the recording, organised by topic, corrected, and extended with questions and exercises.

:::note[What is deliberately left out]
The API key from the slides and the lab machines' password and IP addresses are replaced with placeholders (`<API_KEY>`, `<IP>`). This site is public — create your own key at openweathermap.org.
:::

## Corrections to the slides

- OpenWeatherMap response keys: `main.temp` (not `main.temperature`), `sys.sunrise`, `sys.sunset`, `sys.country`, and the city in `name`.
- The slides' cheat sheet has `add(10 + 20)` — it should be `add(10, 20)`.
- The click example calls a `validate_schema()` function that the slides never define; the notes contain a complete, tested `workflow.py`.
