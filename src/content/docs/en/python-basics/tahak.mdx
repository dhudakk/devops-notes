## Types, input, and output

<div class="sheet-grid">

```python title="Types and conversions" wrap
type(42)          # <class 'int'>
int("42")         # 42
float("3.5")      # 3.5
str(42)           # '42'
int("3.5")        # ValueError
int(3.9)          # 3 (truncates)

bool("")          # False
```

```python title="Input and output" wrap

print("a", "b", sep="-", end="!\n")

print(f"{19.9:.2f} €")      # 19.90 €
```

## Files, exceptions, JSON

<div class="sheet-grid">

```python title="Files" wrap
with open("f.txt", encoding="utf-8") as f:
    text = f.read()     # whole content
    # f.readlines()  → list of lines
    # for line in f: → line by line

# "w" overwrites, "a" appends
with open("f.txt", "a", encoding="utf-8") as f:
    f.write("line\n")   # add \n yourself
```

```python title="Exceptions" wrap
try:
    n = int(input("Number: "))
except ValueError:
    print("Not a number")
else:
    print("OK")       # if no error happened
finally:
    print("Always")

raise ValueError("Bad value")
```

```python title="JSON" wrap
import json

# write
with open("d.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False,
              indent=2)

# read
with open("d.json", encoding="utf-8") as f:
    data = json.load(f)
```

## Exam traps

| Trap | Correct |
| --- | --- |
| `input()` returns text, `"5" + 1` is a `TypeError` | `int(input())` |
| `range(1, 5)` stops at `4` | `range(1, 6)` for 1–5 |
| `if x = 5:` | `if x == 5:` |
| `elif` with a looser condition first | strictest condition first |
| `xs = xs.sort()` → `None` | `xs.sort()` or `xs = sorted(xs)` |
| `b = a`, then changing `b` changes `a` too | `b = a.copy()` |
| `name.upper()` without assignment changes nothing | `name = name.upper()` |
| a function that prints instead of returning gives `None` | `return result` |
| `def f(a=1, b):` | default parameters go last |
| `def f(items=[])` — the list is shared between calls | `items=None`, then `if items is None: items = []` |
| `{}` is an empty dictionary | an empty set is `set()` |
| `open(..., "w")` erases the file | `"a"` to append |
| bare `except:` | `except ValueError:` |
| `0.1 + 0.2 == 0.3` is `False` | `round(...)` or `math.isclose()` |
