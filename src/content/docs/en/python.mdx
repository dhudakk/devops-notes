## How to use these notes

Read each topic once without copying the code. Then type the examples yourself, change the inputs, and predict the output before running them. Finally, move to the [exercises](/devops-notes/en/cvicenia/) and split every solution into **input → processing → output**.

The automatic transcript was treated as a source, not as finished course material. Terminology and examples were corrected to match real Python behavior while preserving the meaning of the lesson.
:::
