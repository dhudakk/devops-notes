## How to approach an exercise

1. **Input → processing → output.** First write down what data the program gets, what it does with it, and what it prints.
2. **Predict the result** before running it. If it differs, find out why — that is where you learn the most.
3. **Test the edge values:** exactly `0`, `15`, `18`, empty input, text instead of a number.

Checklist before handing in:

- The program runs without a syntax error.
- Variable and function names say what they hold or do.
- Every loop has a clear exit condition.
- An error state prints an understandable message, not a traceback.
- Repeated logic lives in a function.
