A string (`str`) is an immutable sequence of Unicode characters. It can be indexed and sliced like a list, but individual characters cannot be changed in place.

```python
language = "Python"

print(language[0])     # P
print(language[-1])    # n
print(language[1:4])   # yth
print(len(language))   # 6
```

## Cleaning and normalization

```python
raw_name = "  mARy sMIth  "

clean_name = raw_name.strip().title()
print(clean_name)  # Mary Smith
```

Common methods:

| Method | Use |
| --- | --- |
| `.strip()` | removes surrounding whitespace |
| `.lower()`, `.upper()` | changes letter case |
| `.title()` | capitalizes words |
| `.replace(old, new)` | replaces occurrences |
| `.startswith(prefix)` | tests the beginning |
| `.endswith(suffix)` | tests the ending |
| `.find(text)` | first matching index or `-1` |

For case-insensitive user input, `.casefold()` is often more robust than `.lower()`, especially across languages.

```python
answer = input("Yes or no? ").strip().casefold()

if answer == "yes".casefold():
    print("Confirmed")
```

## `split()` and `join()`

`split()` divides a string into a list. `join()` performs the opposite operation.

```python
line = "python,git,terraform"
topics = line.split(",")

label = " · ".join(topics)
print(label)  # python · git · terraform
```

User-entered data usually needs each part cleaned as well.

```python
raw_topics = " Python, Git , Kubernetes "
topics = [topic.strip() for topic in raw_topics.split(",")]

print(topics)
```

The expression in brackets is a **list comprehension** — a compact way to build a list by transforming another collection.

## Formatting with f-strings

```python
name = "Eva"
completed = 7
total = 8
ratio = completed / total

print(f"{name}: {completed}/{total} ({ratio:.0%})")
```

The `:.0%` format multiplies by 100, adds `%`, and displays no decimal places.

## Basic email processing

```python title="email.py"
email = input("Email: ").strip().casefold()
local_part, separator, domain = email.partition("@")

is_basic_format_valid = bool(local_part and separator and "." in domain)

if is_basic_format_valid:
    print(f"User: {local_part}")
    print(f"Domain: {domain}")
else:
    print("The email does not have the expected basic format.")
```

:::caution[This is not complete email validation]
Email address rules are complex. In production, use a trusted library and verify ownership by sending a confirmation link.
:::

## Strings are immutable

```python
word = "python"
# word[0] = "P"  # TypeError

word = "P" + word[1:]
print(word)  # Python
```

Methods such as `.replace()` and `.upper()` return a new string; they do not change the original.

## Remember

- A string is an immutable sequence of characters.
- Clean input with `strip()` and normalize case when appropriate.
- `split()` divides; `join()` combines.
- F-strings are the clearest way to build formatted output.
