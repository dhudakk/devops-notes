A dictionary (`dict`) maps a unique key to a value. A set (`set`) stores unique items without indexing.

## Dictionaries

```python
student = {
    "name": "Eva",
    "course": "Python",
    "completed_lessons": 6,
    "active": True,
}

print(student["name"])
print(student.get("email", "Email not provided"))
```

Accessing `student["email"]` raises `KeyError` when the key is missing. `.get()` safely returns a default value.

## Adding, changing, and removing

```python
student["email"] = "eva@example.com"
student["completed_lessons"] += 1

removed_value = student.pop("active", None)
print(removed_value)  # True
```

## Iteration

```python
for key, value in student.items():
    print(f"{key}: {value}")
```

`.keys()` iterates over keys, `.values()` over values, and `.items()` over `(key, value)` pairs.

## Nested records

```python title="course_data.py"
participants = [
    {"name": "Eva", "score": 92},
    {"name": "Mark", "score": 74},
    {"name": "Susan", "score": 88},
]

best = max(participants, key=lambda participant: participant["score"])
average = sum(item["score"] for item in participants) / len(participants)

print(f"Best result: {best['name']} ({best['score']}%)")
print(f"Average: {average:.1f}%")
```

A list is suitable for the collection of participants, while a dictionary represents the named properties of each participant.

## Sets

A set automatically removes duplicates and supports mathematical set operations.

```python
day_one = {"Eva", "Mark", "Susan"}
day_two = {"Eva", "Susan", "Peter"}

print(day_one & day_two)  # intersection: both days
print(day_one | day_two)  # union: at least one day
print(day_one - day_two)  # first day only
print(day_one ^ day_two)  # exactly one of the days
```

Removing duplicates from a list is simple:

```python
topics = ["Python", "Git", "Python", "Docker"]
unique_topics = set(topics)
print(unique_topics)
```

Set order is not guaranteed. Use `sorted(unique_topics)` when you need stable, sorted output.

## Saving an object with `pickle`

`pickle` serializes Python objects into a binary file.

```python title="save_state.py"
import pickle

progress = {"lesson": 8, "completed": True}

with open("progress.pkl", "wb") as file:
    pickle.dump(progress, file)

with open("progress.pkl", "rb") as file:
    restored_progress = pickle.load(file)

print(restored_progress)
```

:::danger[Never load an untrusted pickle]
`pickle.load()` can execute arbitrary code while loading. Use it only for files you created and control. JSON is often a better format for exchanging data between systems.
:::

## Choosing a collection

| Need | Type |
| --- | --- |
| Ordered values that can change | `list` |
| Fixed ordered group | `tuple` |
| Values accessed by named keys | `dict` |
| Unique items and set operations | `set` |

## Remember

- A dictionary stores key–value pairs.
- `.get()` is useful when a key may be missing.
- A set removes duplicates but does not promise stable order.
- Untrusted `pickle` files are a security risk.
