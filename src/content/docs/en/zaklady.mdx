A Python program is a sequence of precise instructions. When designing one, it helps to divide the problem into three parts:

1. **Input** — what data does the program need?
2. **Processing** — what calculations or decisions should it perform?
3. **Output** — what result should the user receive?

This is the **IPO model** (*Input–Process–Output*). Before writing code, we can describe a solution with pseudocode or a flowchart.

## Your first output

The `print()` function displays a value in the console. Text data — `str` — is written inside quotes.

```python title="hello.py"
print("Hello, Python!")
print('Both single and double quotes are valid.')
```

The `#` character starts a comment. Python ignores the rest of that line while executing the program.

```python
# This comment explains the intention of the next line.
print("Order system")  # A short comment can also follow code.
```

:::tip
A comment should explain **why**, not mechanically repeat what the code already says.
:::

## Variables and naming

A variable is a name that refers to a value. Python is dynamically typed: the type belongs to the value and can change at runtime. In practice, avoid changing the meaning of a variable without a good reason.

```python
product_name = "Mechanical keyboard"
quantity = 2
unit_price = 89.90
is_available = True
```

Good names are lowercase and descriptive, with words separated by underscores (`snake_case`). Python is case-sensitive: `price` and `Price` are two different names.

A Python constant is not technically locked. Uppercase letters are a convention that means “do not change this value.”

```python
VAT_RATE = 0.20
ADMIN_FEE = 2.50
```

## Basic data types

| Type | Meaning | Example |
| --- | --- | --- |
| `str` | text | `"Python"` |
| `int` | integer | `42` |
| `float` | decimal number | `19.90` |
| `bool` | true/false value | `True`, `False` |
| `None` | no/missing value | `None` |

Use `type()` to inspect the type of a value:

```python
lesson_count = 8
print(type(lesson_count))  # <class 'int'>
```

## User input

`input()` always returns a string — even when the user types a number. Convert it before doing arithmetic.

```python title="order.py"
product = input("Product name: ")
quantity = int(input("Quantity: "))
unit_price = float(input("Price per item: "))

subtotal = quantity * unit_price
print(f"{product}: €{subtotal:.2f}")
```

An f-string inserts values directly into text. The `:.2f` format displays a decimal number with two places.

:::caution[What if the user types “two”?]
`int("two")` raises a `ValueError`. We will handle it with `try`/`except` later; for now, make the prompt unambiguous.
:::

## Arithmetic operators

```python
a = 17
b = 5

print(a + b)   # 22     addition
print(a - b)   # 12     subtraction
print(a * b)   # 85     multiplication
print(a / b)   # 3.4    true division
print(a // b)  # 3      floor division
print(a % b)   # 2      remainder
print(a ** b)  # 141985 exponentiation
```

Operator precedence resembles mathematics: parentheses, powers, multiplication/division, then addition/subtraction. Use parentheses whenever the intention may be unclear.

```python
total = (unit_price * quantity) + ADMIN_FEE
```

## Formatting output

`print()` separates arguments with a space and ends with a newline. The `sep` and `end` parameters change this behavior.

```python
print("2026", "09", "12", sep="-")  # 2026-09-12
print("Loading", end="... ")
print("done")                          # Loading... done
```

Escape sequences represent special characters:

```python
print("First line\nSecond line")
print("Name:\tPython")
print("They said: \"Hello\"")
print("C:\\Users\\student")
```

## Complete example: an order

```python title="order_summary.py" {8-10}
ADMIN_FEE = 2.50

customer = input("Customer name: ")
product = input("Product: ")
quantity = int(input("Quantity: "))
unit_price = float(input("Unit price (€): "))

subtotal = quantity * unit_price
total = subtotal + ADMIN_FEE

print("\n--- Order summary ---")
print(f"Customer: {customer}")
print(f"Item: {quantity}× {product}")
print(f"Subtotal: €{subtotal:.2f}")
print(f"Administration fee: €{ADMIN_FEE:.2f}")
print(f"Total: €{total:.2f}")
```

:::note[Money in real applications]
`float` is fine for learning, but cannot represent every decimal value exactly. Production financial systems commonly use `decimal.Decimal` or store amounts as integer cents.
:::

## Remember

<ul class="checklist">
  <li><code>input()</code> returns a <code>str</code>; use <code>int()</code> or <code>float()</code> for numbers.</li>
  <li>Standard Python indentation is <strong>4 spaces</strong>, not a tab.</li>
  <li>Expressions calculate values, variables name them, and <code>print()</code> displays them.</li>
  <li>Replace “magic numbers” with named constants.</li>
</ul>
