A list (`list`) stores an ordered collection of values and can be changed. A tuple (`tuple`) is also ordered, but immutable after creation.

```python
topics = ["Python", "Git", "Terraform"]
coordinates = (48.1486, 17.1077)
```

## Indexes and slices

Indexing starts at zero. A negative index counts from the end.

```python
topics = ["Python", "Git", "Terraform", "Kubernetes"]

print(topics[0])      # Python
print(topics[-1])     # Kubernetes
print(topics[1:3])    # ['Git', 'Terraform']
print(topics[:2])     # ['Python', 'Git']
```

As with `range()`, the right boundary of a slice is excluded.

## Modifying a list

```python title="list_operations.py"
participants = ["Eva", "Mark"]

participants.append("Susan")
participants.insert(1, "Adam")
participants.remove("Mark")
last_added = participants.pop()

print(participants)  # ['Eva', 'Adam']
print(last_added)    # Susan
```

Useful operations:

| Expression | Result |
| --- | --- |
| `len(items)` | number of items |
| `value in items` | membership test |
| `items.sort()` | sorts the original list |
| `sorted(items)` | returns a new sorted list |
| `items.count(x)` | number of occurrences of `x` |

## Beware of shared lists

Assignment does not create a copy. Both names refer to the same object.

```python
original = [1, 2, 3]
alias = original
copy = original.copy()

alias.append(4)

print(original)  # [1, 2, 3, 4]
print(copy)      # [1, 2, 3]
```

For a flat list, `.copy()` or `[:]` is enough. Nested mutable objects may require `copy.deepcopy()`.

## Iterating over a list

```python
prices = [12.50, 8.90, 25.00]
total = 0.0

for price in prices:
    total += price

print(f"Total: €{total:.2f}")
```

Use `enumerate()` when you need both the value and its position.

```python
for position, topic in enumerate(topics, start=1):
    print(f"{position}. {topic}")
```

## Nested lists

A table can be represented as a list of rows.

```python title="matrix.py"
attendance = [
    [True, True, False],
    [True, False, True],
]

for student_number, days in enumerate(attendance, start=1):
    attended = sum(days)  # True behaves like 1 when summed.
    print(f"Student {student_number}: {attended} days")
```

## When to use a tuple

A tuple works well for a fixed group of values, such as an RGB color, coordinates, or multiple function results.

```python
primary_color = (76, 224, 179)
latitude, longitude = (48.1486, 17.1077)
```

Immutability is not absolute protection: if a tuple contains a list, that nested list can still be changed.

## Remember

- A `list` is mutable; a `tuple` is not.
- The first item has index `0`, and the last has index `-1`.
- The right boundary of a slice is excluded.
- `alias = original` does not create a copy.
