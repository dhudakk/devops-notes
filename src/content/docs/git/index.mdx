## Priebeh kurzu

1. **Deň 1** — čo je verzionovací systém, inštalácia a `git config`, lokálna práca: `init`, `status`, `add`, `commit`, `diff`, `log`, `show`, `rm`, `mv`, `.gitignore`, vrátenie zmien (`restore`, `revert`, `reset`). Poobede webové rozhranie GitHub/GitLab, SSH kľúč, `clone` a `push`.
2. **Deň 2** — vetvy (`checkout -b`, `switch`), `merge` a riešenie konfliktov, spolupráca cez remote (`fetch`, `pull`, odmietnutý push, simulácia kolegu druhým clonom), `stash`, tagy, `rebase` a detached HEAD.

:::tip[Päť príkazov na každý deň]
> „Na reálnu prácu potrebujete iba pár príkazov.“

`git status` → `git add` → `git commit -m "…"` → `git push`, a pred prácou `git pull`. Ostatné si vždy vieš dohľadať — dôležité je rozumieť, čo robia.
:::
