## Projekt kurzu

Počas celého kurzu staviame jeden workflow:

<Pipeline steps={[{ group: 'Healthcheck', steps: ['OpenWeatherMap', 'RustFS'] }, 'Scrape Data', 'Validate Data', 'Process Data', 'Publish Data → S3']} caption="Scrape posiela JSON, Process vracia CSV riadok. Od 4. dňa po publikovaní nasleduje DAG report_builder (spúšťa ho asset)." />

1. **Deň 1** — workflow ako Python skript rozdelený na tri funkcie: funkcie, HTTP, JSON, CSV a výnimky.
2. **Deň 2** — zo skriptu nástroj príkazového riadku (click); potom Apache Airflow: inštalácia, prvý DAG, tasky a XCom, Connections a Variables.
3. **Deň 3** — Airflow ako systemd služba; validácia dát JSON schémou, štruktúra projektu (pathlib, `constants.py`), logovanie a chyby, healthchecky (ping, sh, HTTP) bežiace paralelne s opakovaním. Zo slajdov: RustFS/S3 a boto3, skupiny taskov a dynamické mapovanie pre viac miest.
4. **Deň 4** — skupiny taskov, názvy spojení ako konštanty a `helpers.py`; dataset sa ukladá do S3 (RustFS, boto3, dočasné súbory) a jeho aktualizácia cez **assety** spúšťa druhý DAG `report_builder`.
5. **Ďalej** — report, notifikácie do mobilu (Pushbullet — appku si nainštaluj vopred) a dynamické mapovanie taskov pre viac miest.
