## Projekt kurzu

Počas celého kurzu staviame jeden workflow:

```text
[ Scrape Data ] -- json --> [ Process Data ] -- csv --> [ Publish Data ]
```

1. **Deň 1** — workflow ako Python skript: funkcie, HTTP, JSON, CSV, CLI a výnimky.
2. **Ďalšie dni** — ten istý workflow v Apache Airflow: plánovanie, logy, opakovanie a dohľad.
