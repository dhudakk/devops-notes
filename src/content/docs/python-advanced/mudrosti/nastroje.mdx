## httpie namiesto curl

`http` (balík **httpie**) je HTTP klient pre príkazový riadok napísaný v Pythone. Oproti `curl`:

- query parametre píšeš samostatne cez `==`, nemusíš skladať celú URL,
- JSON odpovede automaticky naformátuje a vyfarbí, ukáže aj hlavičky.

```bash
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric
```

## JSON nikdy nespracúvaj grepom

> „Zabudnite na to, že grepom si to vytiahnete. Najväčšia blbosť, ktorú by ste spravili.“

Na JSON je **jq**. S JSON-om sa budeš stretávať stále — pri HTTP, pri reťazení webových služieb — lebo je strojovo čitateľný a ľahko sa prenáša.

```bash
jq .main.temp weather.json
jq -r '[.dt, .name, .main.temp] | @csv' weather.json
```

## Unix: najlepšie rozhranie medzi procesmi je stdin/stdout

Jeden z dizajnových princípov Unixu: malé nástroje, ktoré čítajú zo štandardného vstupu a píšu na štandardný výstup, sa dajú reťaziť cez `|`. Nepíš medzivýsledky do súborov, keď ich môžeš poslať rúrou.

```bash
scrape_data | process_data | publish_data
```

<p class="wisdom-day">Deň 1</p>

## tee namiesto >>

`tee -a súbor` pripojí výstup do súboru **a zároveň** ho ukáže na obrazovke — vidíš, čo sa zapisuje. Duplicitné riadky odstrániš napr. cez `sort -u` (alebo `sort | uniq`).

## crontab je legacy

`crontab` sa v nových systémoch už často ani neinštaluje — nahrádzajú ho **systemd timery** (`systemctl list-timers`). A aj CI/CD pipeline je plánované spúšťanie úloh, len spúšťačom nie je čas, ale udalosť (commit, push).

## Swap a zram, keď dochádza RAM

Na stroji so 4 GB RAM Airflow ľahko minie pamäť — stroj zamrzne a padá SSH. Rýchla pomoc je **2 GB swap súbor** (`fallocate`, `mkswap`, `swapon`, `free -h`). Mirek chce vyskúšať aj **zram**: jadro komprimuje časť RAM za behu, takže zo 4 GB je efektívne viac, za cenu trochu výkonu. Na jeho starých Raspberry Pi s 1 GB RAM to „vie celkom elegantne pomôcť“.

## Airflow ako systemd služba

Mirekov pokus z 3. dňa: namiesto tmux-u spúšťať Airflow ako **systemd unit**. Najviac ho láka `KillMode=control-group` — pri zastavení systemd zabije všetko, čo služba naspúšťala, a `Restart=on-failure` ju po páde sám znova spustí. „Toto som ešte nerobil, ale vidím v tom potenciál.“ Postup je v [Inštalácia Airflow](/devops-notes/python-advanced/airflow-instalacia/#systemd-služba).

## Swap po reštarte zmizne

Mirekovi na 3. deň opäť zamŕzal stroj — swap mal po reštarte nulový. `swapon` platí iba do reštartu; natrvalo ho zapneš riadkom v `/etc/fstab`:

```text
/swapfile none swap sw 0 0
```

## sh — príkazy ako Python funkcie

Na spúšťanie príkazov z Pythonu je `os.system`, `subprocess`… ale modul **sh** je „extrémne user friendly“: `from sh import ping` a `ping("-c", 1, host)`. Má aj vychytávky ako `_timeout=3`. „Keď budete robiť so shellom a nebudete špekulovať nad masakrálnymi vecami, tento modul je úplne šupa.“ Viac v [Healthcheck](/devops-notes/python-advanced/healthcheck/#spôsob-2-modul-sh).

## JSON schému si nechaj vygenerovať

Schému netreba písať od nuly:

- [jsonschemavalidator.net](https://www.jsonschemavalidator.net/) — vľavo schéma, vpravo dokument, chyby vidíš hneď,
- online generátory (*JSON schema from document*) vytvoria kostru zo vzorového JSON-u,
- Claude či ChatGPT pridajú aj rozsahy a popisy — stačí povedať, že ide o odpoveď z openweathermap.org.

## mktemp na dočasné súbory

Aj v Bash skriptoch občas potrebuješ dočasný súbor. Nevymýšľaj meno — `mktemp` vytvorí súbor s jedinečným menom v `/tmp` (`-d` priečinok, `-u` iba vypíše meno). V Pythone je ekvivalent `tempfile.mkstemp()`.

## cloc — koľko kódu máme

`cloc` (*count lines of code*) spočíta riadky kódu podľa jazyka. Celý projekt z kurzu mal po 4. dni okolo 200 riadkov Pythonu — a to v každom module je niekoľko riadkov importov.

## Apprise aj do Bash skriptov

`pip install apprise` pridá aj príkaz `apprise` — z ľubovoľného skriptu pošleš notifikáciu do mobilu: `echo "záloha hotová" | apprise "pbul://$token"`. Tá istá syntax URL funguje pre desiatky služieb.
