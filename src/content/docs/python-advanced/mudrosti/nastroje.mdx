## httpie namiesto curl

`http` (balík **httpie**) je HTTP klient pre príkazový riadok napísaný v Pythone. Oproti `curl`:

- query parametre píšeš samostatne cez `==`, nemusíš skladať celú URL,
- JSON odpovede automaticky naformátuje a vyfarbí, ukáže aj hlavičky.

```bash
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric
```

## JSON nikdy nespracúvaj grepom

> „Zabudnite na to, že grepom si to vytiahnete. Najväčšia blbosť, ktorú by ste spravili.“

Na JSON je **jq**. S JSON-om sa budeš stretávať stále — pri HTTP, pri reťazení webových služieb — lebo je strojovo čitateľný a ľahko sa prenáša.

```bash
jq .main.temp weather.json
jq -r '[.dt, .name, .main.temp] | @csv' weather.json
```

## Unix: najlepšie rozhranie medzi procesmi je stdin/stdout

Jeden z dizajnových princípov Unixu: malé nástroje, ktoré čítajú zo štandardného vstupu a píšu na štandardný výstup, sa dajú reťaziť cez `|`. Nepíš medzivýsledky do súborov, keď ich môžeš poslať rúrou.

```bash
scrape_data | process_data | publish_data
```

## tee namiesto >>

`tee -a súbor` pripojí výstup do súboru **a zároveň** ho ukáže na obrazovke — vidíš, čo sa zapisuje. Duplicitné riadky odstrániš napr. cez `sort -u` (alebo `sort | uniq`).

## crontab je legacy

`crontab` sa v nových systémoch už často ani neinštaluje — nahrádzajú ho **systemd timery** (`systemctl list-timers`). A aj CI/CD pipeline je plánované spúšťanie úloh, len spúšťačom nie je čas, ale udalosť (commit, push).

## Swap a zram, keď dochádza RAM

Na stroji so 4 GB RAM Airflow ľahko minie pamäť — stroj zamrzne a padá SSH. Rýchla pomoc je **2 GB swap súbor** (`fallocate`, `mkswap`, `swapon`, `free -h`). Mirek chce vyskúšať aj **zram**: jadro komprimuje časť RAM za behu, takže zo 4 GB je efektívne viac, za cenu trochu výkonu. Na jeho starých Raspberry Pi s 1 GB RAM to „vie celkom elegantne pomôcť“.
