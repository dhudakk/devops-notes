## PyCharm je najlepšie IDE…

> „PyCharm je to najlepšie prostredie, ktoré viete použiť, preto ho nebudeme používať.“

Na kurze ide všetko cez **VS Code** — kvôli práci na vzdialenom serveri cez SSH a jednotnému prostrediu pre všetkých.

## Ruff vytlačil Black

Donedávna bol najobľúbenejší formátovač **Black**, prvenstvo prevzal **Ruff** — je formátovač **aj** linter v jednom. Je napísaný v Ruste, takže je násobne rýchlejší ako Black či Flake8. Vo VS Code ho treba doinštalovať aj ako rozšírenie — inak *Format Document* hlási, že nemá formátovač.

<p class="wisdom-day">Deň 1</p>

## ipython — „výrazne viac sexy“ interpreter

Namiesto obyčajného `python` REPL použi **ipython**: farby, história, a hlavne `objekt.` + `Tab` ukáže všetky vlastnosti a metódy a `premenná?` jej typ a dokumentáciu. Najrýchlejší spôsob, ako preskúmať neznámy objekt (napr. HTTP odpoveď).

V tom je podľa Mireka sila Pythonu: v Jave je to stále dookola *uprav → skompiluj → spusti → pozeraj*. V Pythone si kód „vypipláš“ naživo v ipythone a keď si spokojný, prepíšeš ho do súboru a raz otestuješ.

<p class="wisdom-day">Deň 1</p>

## f-stringy: THIS IS THE WAY

Reťazce nespájaj cez `+` — „nanajvýš ak sú to dva reťazce, a aj vtedy sa zamyslite nad sebou“. Pri dlhšom texte (napr. webová stránka) by si kurzorom hľadal, kde reťazec roztrhnúť a kde spojiť — „to sa ošediviete“. Použi f-string: `f"{url}?q={query}"`.

## „This will never happen“

Najhorší kód, aký môžeš stretnúť:

```python
except Exception as ex:
    # this will never happen
    pass
```

Každú zachytenú výnimku ošetri — aspoň ju zaloguj cez `logging.exception()`.

## Žiadne bulharské konštanty

Čísla bez vysvetlenia (`if status == 404`) sú „bulharské konštanty“. Pomenuj ich: `HTTPStatus.NOT_FOUND`, vlastné konštanty `UPPER_CASE`.

## Všetko zatvor do funkcie

Aj samotný postup workflowu patrí do `main()`, spúšťaný cez `if __name__ == "__main__":`. A DRY — ak sa logika opakuje, patrí do funkcie. (Ale pozor aj na WET: s abstrakciou počkaj, kým sa kód zopakuje 2–3×.)

## Tajomstvá cez premenné prostredia

API kľúč v argumente vidí každý cez `ps aux`. Premenná prostredia sa v zozname procesov nezobrazí — „premenná prostredia nie je proces“.

```bash
APPID=<API_KEY> ./workflow.py kosice
```

## pendulum namiesto datetime, dátumy v ISO 8601

S `datetime` sa nepracuje pohodlne, najmä s časovými zónami — **pendulum** je spätne kompatibilný a príjemnejší. A dátumy zapisuj v ISO 8601 (`2026-05-19T13:07:18Z`), nie po európsky ani „americkou logikou“ `MM/DD/YYYY`.

<p class="wisdom-day">Deň 1</p>

## Čas ukladaj v UTC

Časy ukladaj a počítaj vždy v **UTC** a na lokálny čas ich preveď až pri zobrazení používateľovi. Inak každý záznam z inej krajiny potrebuje vlastný prepočet. Unix timestamp je navyše len celé číslo — „o hodinu neskôr“ je `+ 3600`.

## Keď VS Code nevidí nainštalované balíky

Mirek priznáva, že VS Code je v tomto „nevyspytateľné“. Postup: vyber interpreter z venv (*Python: Select Interpreter*), potom *Python: Restart Language Server* — a keď nepomôže ani to, odpoj sa od servera a pripoj znova.

## Klávesové skratky z IntelliJ

Mirek používa vo VS Code klávesové skratky z IntelliJ (naformátovanie kódu je u neho `Ctrl+Alt+L`). Ak prechádzaš z PyCharmu či IntelliJ, VS Code má na to rozšírenie *IntelliJ IDEA Keybindings*. Predvolené formátovanie vo VS Code je `Shift+Alt+F`.

## Dynamické typovanie

V Pythone prejde `a = 10`, potom `a = "Jano"`, potom `a = True`. V C, Jave či C# by ťa prekladač „poslal kade ľahšie“. Programátori zo staticky typovaných jazykov si na to chvíľu zvykajú — type hinty im (aj editoru) pomôžu, ale za behu nič nekontrolujú.

## Zatváraj súbory

Proces má limit otvorených súborov (`ulimit -n`). Workflow, ktorý ich nezatvára, raz spadne — preto `with open(...)`.
