<KeyPoints>
- **Šablóna** je text so zástupnými miestami (*placeholders*); **model** sú dáta; **render** ich spojí. Oddelíš tak prácu dizajnéra, programátora a databázistu.
- **Jinja** (`pip install jinja2`, Airflow ju už má): `{{ premenná }}` vloží hodnotu, `{% for ... %}…{% endfor %}` je cyklus, `-` pri značke odstráni biele znaky.
- `env = jinja2.Environment(loader=jinja2.FileSystemLoader(TEMPLATES_PATH), autoescape=False)` → `env.get_template("meno.tpl.j2")` → `template.render(model)`.
- **`csv.DictReader(file, delimiter=",")`** zmení každý riadok CSV na slovník podľa hlavičky.
- Report nahráš do S3 priamo z pamäte: `bucket.put_object(Key=..., Body=report, ContentType="text/markdown")`.
- Tretí DAG `midnight_report` beží každú noc (`5 0 * * *`): healthcheck → report → notifikácia.
</KeyPoints>

## Šablóny

Šablónu sme už videli — f-string je šablóna:

```python
name, surname, age = "Sherlock", "Holmes", 33
f"{name} {surname} is {age} years old"
```

Nechceme však text iba pre Sherlocka, ale pre každú osobu z databázy. Miesta, kde sa text mení, nahradíme **zástupnými miestami** (*placeholders*) a dosadíme do nich hodnoty:

| Pojem | Význam |
| --- | --- |
| **model** | dáta, ktoré sa dosadzujú (napr. slovník `{"name": "Juraj", ...}`) |
| **šablóna** (*template*) | text so zástupnými miestami |
| **controller / view** | kód, ktorý vezme model a šablónu, spojí ich a vráti výsledný text |

Je to návrhový vzor **MVC** (*model–view–controller*); webové rámce ho volajú aj **MTV** (*model–template–view*).

Prečo nie stačí print? Šablóny oddelia **role**: grafik či dizajnér rieši vzhľad (šablónu), programátor to spája, databázista sa stará o dáta. Najhoršie, čo môžeš vidieť, je Python kód, ktorý printami skladá HTML stránku — opravovať to je katastrofa.

V čistom Pythone vie dosadiť slovník aj `str.format`:

```python
>>> model = {"name": "Juraj", "surname": "Jánošík", "age": 24}
>>> "{name} {surname} is {age} years old".format(**model)   # alebo .format_map(model)
'Juraj Jánošík is 24 years old'
```

Na viac ako jednoriadkové texty je však lepší šablónovací systém.

## Jinja

**Jinja** je šablónovací systém pre Python. Vychádza zo šablón webového rámca **Django** — jedného z najpopulárnejších v Pythone (vznikol v redakcii novín, preto má výbornú dokumentáciu). Djangove šablóny sa nedali použiť samostatne, tak vznikla Jinja ako samostatná knižnica. Jej štýl sa rozšíril do mnohých jazykov — napr. **Go templates** (Helm, Kubernetes) sú ním silno inšpirované. Používa ju Ansible, Salt, webové rámce (Flask, FastAPI) aj dbt.

```bash
(venv) $ pip install jinja2
```

Balík sa stále volá `jinja2`, hoci aktuálna verzia je 3.x. Airflow ho už má nainštalovaný ako závislosť.

### Základy v ipythone

```python
>>> import jinja2
>>> env = jinja2.Environment()       # configuration shared by templates
>>> template = env.from_string("{{ name }} {{ surname }} is {{ age }} years old")
>>> template.render()
'  is  years old'
>>> template.render(name="Juraj", surname="Jánošík", age=24)
'Juraj Jánošík is 24 years old'
>>> model = {"name": "John", "surname": "Rambo", "age": 32}
>>> template.render(model)
'John Rambo is 32 years old'
```

- Zástupné miesto sú **dvojité** kučeravé zátvorky `{{ … }}` (f-string má jednoduché).
- Hodnota, ktorú nedodáš, sa vyrenderuje ako prázdny reťazec — preto `'  is  years old'`.
- Dáta dodáš ako pomenované argumenty, alebo — častejšie — ako **slovník**.

### Šablóny v súboroch

Šablóny nebudeme mať v kóde, ale v priečinku `~/airflow/templates/`. Prípona `.tpl.j2` — VS Code podľa `.j2` spozná Jinja šablónu. Cestu dáme do konštánt, nech ju nehľadáš po kóde:

```python title="dags/constants.py"
TEMPLATES_PATH = AIRFLOW_HOME / "templates"
MIDNIGHT_TEMPLATE = "midnight-report.tpl.j2"
REPORT_FILE = "midnight-report.md"
```

```python
env = jinja2.Environment(
    loader=jinja2.FileSystemLoader(TEMPLATES_PATH),   # where the templates are
    autoescape=False,
)
template = env.get_template(MIDNIGHT_TEMPLATE)       # just the name — Jinja finds it
report = template.render(model)
```

`autoescape=True` by nahradzoval špeciálne znaky HTML (`<` → `&lt;`) — ochrana pre HTML stránky. Pre Markdown ho vypneme.

## Šablóna reportu (Markdown)

Formát: HTML alebo Markdown? HTML vedela písať asi polovica skupiny, tak lektor zvolil **Markdown** — formátovanie píšeš priamo do textu: `#` je nadpis, `**text**` tučné písmo, tabuľka sa kreslí zvislými čiarami.

```jinja title="templates/midnight-report.tpl.j2"
# Midnight Report

Generated **{{ dt }}**.

| Date and time | City | Country | Temperature (°C) | Humidity (%) | Pressure (hPa) |
| --- | --- | --- | --- | --- | --- |
{% for entry in data -%}
| {{ entry.dt }} | {{ entry.name }} | {{ entry.country }} | {{ entry.temp }} | {{ entry.humidity }} | {{ entry.pressure }} |
{% endfor %}
```

### Cyklus a biele znaky

Riadkov tabuľky môže byť tisíc — nedajú sa napísať napevno. Jinja má **riadiace príkazy** v `{% … %}`: cykly, podmienky, priradenia, volania funkcií.

- `{% for entry in data %}` … `{% endfor %}` zopakuje obsah pre každú položku zoznamu `data`; aktuálna položka je v `entry`.
- `entry` je slovník — `{{ entry.dt }}` aj `{{ entry["dt"] }}` funguje (overené). Nezabudni na `{{ }}` — bez nich Jinja vypíše text tak, ako je.
- **Biele znaky:** samotná značka `{% for %}` zanechá vo výsledku prázdny riadok. Mínus pri značke (`-%}` alebo `{%-`) odstráni biele znaky na tej strane — vďaka `-%}` sú riadky tabuľky tesne za sebou.
- Jednotky (°C, %, hPa) dáme do hlavičky tabuľky, nie ku každej hodnote.

## Dáta z CSV: csv.DictReader

Model pre šablónu potrebuje zoznam slovníkov:

```python
model = {
    "dt": "2026-09-25T13:49:55+02:00",
    "data": [
        {"dt": "…", "name": "Kosice", "country": "SK", "temp": "15.8", "humidity": "67", "pressure": "1018"},
        ...
    ],
}
```

Dataset je CSV. Bez pandas (na kurze sme ho pre nedostatok času nebrali) pomôže štandardný modul **`csv`**. Jeho **`DictReader`** z každého riadku spraví slovník — kľúče vezme z **hlavičky** (prvý riadok):

```python
import csv

with open(path, encoding="utf-8") as file:
    reader = csv.DictReader(file, delimiter=",")
    for row in reader:              # reader is iterable — one dictionary per row
        model["data"].append(row)
```

- `delimiter` je oddeľovač stĺpcov — u nás čiarka (lektor mal bodkočiarku `";"`).
- **Súbor musí mať hlavičku.** Bez nej by si k hodnotám pristupoval iba cez index (`line.split(",")[1]`). Lektorovi aj časti účastníkov hlavička chýbala — doplnili ju a nahrali novú verziu súboru cez konzolu RustFS.
- Alternatíva je čítať súbor riadok po riadku (`file.readline()`), ale `DictReader` je pohodlnejší.

## DAG midnight_report

<Pipeline steps={['is_rustfs_alive', 'create_report', 'notify_report']} caption="Každú noc o 0:05 UTC." />

Tretí DAG projektu (prvý beží každých 20 minút, druhý ho spúšťa asset, tretí raz denne):

1. healthcheck RustFS (zdieľaný `is_rustfs_alive` z `tasks.py`),
2. `create_report`: stiahne dataset do dočasného súboru (keď chýba → `AirflowFailException`), načíta ho cez `DictReader`, vyrenderuje šablónu a nahrá report do S3; vo `finally` zmaže dočasný súbor,
3. notifikácia, že report je pripravený (`send_notification` z [Notifikácií](/devops-notes/python-advanced/notifikacie/)).

Aktuálny čas do reportu: `pendulum.now().to_iso8601_string()` — pendulum si časovú zónu zistí sám.

Bez pandas nevieme jednoducho rátať minimum, maximum či priemer za včerajšok — report je zatiaľ celý dataset ako tabuľka.

### Nahratie reportu: put_object

`template.render()` vráti **reťazec**. Netreba ho ukladať do súboru — `put_object` nahrá obsah priamo z pamäte:

```python
bucket.put_object(Key=REPORT_FILE, Body=report, ContentType="text/markdown")
```

- `Body` môže byť reťazec (aj `report.encode("utf-8")`),
- `ContentType` je MIME typ — pre Markdown `text/markdown`. Prehliadač a konzola podľa neho vedia, čo s obsahom robiť.
- Pozor na preklep: s `context_type=` boto3 zlyhá — `ParamValidationError: Unknown parameter in input: "context_type", must be one of: ACL, Body, Bucket, …`. Na kurze kvôli tomu ostal visieť beh DAG-u a pomohol až reštart Airflow.

Alternatíva: zapísať report do dočasného súboru a nahrať ho cez `upload_file`.

### Ako si report pozrieť

- V konzole RustFS: objekt → *Preview*, alebo *Generate URL* a stiahnuť (`wget <url>`).
- Vo VS Code otvor `.md` súbor a vpravo hore klikni na *Open Preview to the Side* (`Ctrl+K V`) — vedľa zdroja uvidíš vyrenderovaný Markdown s tabuľkou. Rozšírenie netreba, je vstavané.

```python title="dags/helpers.py"
"""Helper functions shared by several DAGs."""

import logging

import boto3
from airflow.sdk import BaseHook, Variable
from apprise import Apprise

from constants import RECEIVERS_VAR, S3_CONN

logger = logging.getLogger(__name__)


def get_storage():
    """Return a boto3 S3 resource for the RustFS connection."""
    conn = BaseHook.get_connection(S3_CONN)
    return boto3.resource(
        "s3",
        endpoint_url=f"{conn.schema}://{conn.host}:{conn.port}",
        aws_access_key_id=conn.login,
        aws_secret_access_key=conn.password,
    )


def send_notification(title: str, body: str) -> None:
    """Send a push notification to every receiver from the Variable (one per line)."""
    apprise = Apprise()
    for receiver in Variable.get(RECEIVERS_VAR, default="").split():
        apprise.add(receiver)
    if not apprise.notify(title=title, body=body):
        logger.warning("Notification was not delivered: %s", title)
```

```python title="dags/weather_scraper.py"
"""Weather scraper: healthchecks -> scrape -> validate -> process -> publish to S3."""

import json
import logging
from datetime import timedelta
from http import HTTPStatus
from pathlib import Path
from tempfile import mkstemp

import httpx
import jsonschema
from airflow.sdk import (
    BaseHook,
    Param,
    Variable,
    dag,
    get_current_context,
    task,
    task_group,
)
from airflow.sdk.exceptions import AirflowException, AirflowFailException
from botocore.exceptions import ClientError
from pendulum import datetime, from_timestamp

from assets import WEATHER_DATA
from constants import BUCKET_NAME, CSV_HEADER, DATASET_FILE, SCHEMA_PATH, WEATHER_CONN
from helpers import get_storage, send_notification
from tasks import is_rustfs_alive

logger = logging.getLogger(__name__)


@task.bash(task_display_name="Ping OpenWeatherMap")
def is_service_alive_in_bash() -> str:
    conn = BaseHook.get_connection(WEATHER_CONN)
    return f"ping -c 1 -w 2 {conn.host}"


@task(
    task_display_name="OpenWeatherMap Healthcheck",
    retries=3,
    retry_delay=timedelta(seconds=10),
)
def is_service_alive() -> None:
    conn = BaseHook.get_connection(WEATHER_CONN)
    url = f"{conn.schema}://{conn.host}:{conn.port}"
    response = httpx.head(url, follow_redirects=True, timeout=10)
    if response.status_code != HTTPStatus.OK:
        raise AirflowException(f"OpenWeatherMap unavailable: HTTP {response.status_code}")


@task(task_display_name="Get Locations")
def get_locations() -> list[str]:
    """Cities for this run — from the Trigger form, or the default from the Variable."""
    context = get_current_context()
    return context["params"]["query"]


@task(task_display_name="Scrape Data")
def scrape_data(query: str) -> dict:
    logger.info("Scraping data for %s", query)
    conn = BaseHook.get_connection(WEATHER_CONN)
    url = f"{conn.schema}://{conn.host}:{conn.port}/data/2.5/weather"
    params = {
        "q": query,
        "appid": conn.password,
        "units": conn.extra_dejson.get("units", "metric"),
    }
    response = httpx.get(url, params=params, timeout=10)
    if response.status_code != HTTPStatus.OK:
        logger.warning("OpenWeatherMap answered HTTP %s", response.status_code)
        raise AirflowFailException(f"Cannot get weather for {query}: {response.text}")
    return response.json()


@task(task_display_name="Validate Data")
def validate_data(payload: dict) -> dict:
    schema = json.loads(SCHEMA_PATH.read_text(encoding="utf-8"))
    try:
        jsonschema.validate(instance=payload, schema=schema)
    except jsonschema.ValidationError as error:
        logger.error("Unexpected data from the service: %s", error.message)
        raise AirflowFailException("The data does not match the schema.") from error
    return payload


@task(task_display_name="Process Data")
def process_data(data: dict) -> str:
    values = [
        from_timestamp(data["dt"]).to_iso8601_string(),
        data["name"],
        data["sys"]["country"],
        data["main"]["temp"],
        data["main"]["humidity"],
        data["main"]["pressure"],
        data["wind"]["speed"],
        data["wind"]["deg"],
    ]
    return ",".join(str(value) for value in values)


@task(task_display_name="Notify")
def notify(data: dict) -> None:
    send_notification(
        title=f"Aktuálne počasie v {data['name']}",
        body=(
            f"Teplota je {data['main']['temp']} °C, "
            f"vlhkosť {data['main']['humidity']} %, "
            f"tlak {data['main']['pressure']} hPa."
        ),
    )


# one city at a time: all mapped instances append to the same dataset.csv
@task(
    task_display_name="Publish Data",
    outlets=[WEATHER_DATA],
    max_active_tis_per_dagrun=1,
)
def publish_data(line: str) -> None:
    """Download the dataset from S3, append the line, upload it back."""
    bucket = get_storage().Bucket(BUCKET_NAME)
    _, temp_name = mkstemp(prefix="weather-", suffix=".csv")  # _ = fd we do not need
    path = Path(temp_name)
    try:
        try:
            bucket.download_file(DATASET_FILE, str(path))
        except ClientError:
            logger.warning("Dataset file not found, probably first dataset upload.")
            with open(path, "w", encoding="utf-8") as file:
                print(CSV_HEADER, file=file)

        with open(path, "a", encoding="utf-8") as file:
            print(line, file=file)

        bucket.upload_file(str(path), DATASET_FILE)
        logger.info("Dataset uploaded to s3://%s/%s", BUCKET_NAME, DATASET_FILE)
    finally:
        path.unlink(missing_ok=True)  # runs even when something above fails


@task_group(
    group_id="tg_healthcheck",
    group_display_name="Healthcheck",
    tooltip="Healthcheck of external services.",
)
def tg_healthcheck():
    return [is_service_alive_in_bash(), is_service_alive(), is_rustfs_alive()]


@task_group(
    group_display_name="Weather Ingestion",
    tooltip="Retrieve, process and upload weather info.",
)
def tg_weather_ingestion(query: str):
    data = scrape_data(query)
    valid_data = validate_data(data)
    notify(valid_data)
    line = process_data(valid_data)
    publish_data(line)


@dag(
    "weather_scraper",
    dag_display_name="Weather Scraper",
    description="Scrapes weather from openweathermap.org",
    schedule="*/20 * * * *",
    start_date=datetime(2026, 1, 1),
    tags=["weather", "devops"],
    catchup=False,
    params={
        "query": Param(
            default=Variable.get("weather_city", default="kosice,sk").split(),
            type="array",
            title="Locations",
            description="List of locations. One location per line.",
        ),
    },
)
def main():
    locations = tg_healthcheck() >> get_locations()
    tg_weather_ingestion.expand(query=locations)


if __name__ == "__main__":
    main().test()
else:
    main()
```

```python title="dags/midnight_report.py"
"""Midnight report: every night, render the whole dataset as a Markdown table into S3."""

import csv
import logging
from pathlib import Path
from tempfile import mkstemp

import jinja2
import pendulum
from airflow.sdk import dag, task
from airflow.sdk.exceptions import AirflowFailException
from botocore.exceptions import ClientError

from constants import (
    BUCKET_NAME,
    DATASET_FILE,
    MIDNIGHT_TEMPLATE,
    REPORT_FILE,
    TEMPLATES_PATH,
)
from helpers import get_storage, send_notification
from tasks import is_rustfs_alive

logger = logging.getLogger(__name__)


@task(task_display_name="Create Report")
def create_report() -> None:
    bucket = get_storage().Bucket(BUCKET_NAME)
    _, temp_name = mkstemp(prefix="report-", suffix=".csv")
    path = Path(temp_name)
    try:
        # download the dataset
        try:
            bucket.download_file(DATASET_FILE, str(path))
        except ClientError as error:
            logger.warning("Dataset file not found. Nothing to do.")
            raise AirflowFailException("Dataset file not found.") from error

        # model: every CSV row becomes a dictionary (keys from the header)
        model = {"dt": pendulum.now().to_iso8601_string(), "data": []}
        with open(path, encoding="utf-8") as file:
            reader = csv.DictReader(file, delimiter=",")
            for row in reader:
                model["data"].append(row)

        # template + model -> report
        env = jinja2.Environment(
            loader=jinja2.FileSystemLoader(TEMPLATES_PATH),
            autoescape=False,
        )
        template = env.get_template(MIDNIGHT_TEMPLATE)
        report = template.render(model)

        # upload straight from memory, no local file needed
        bucket.put_object(Key=REPORT_FILE, Body=report, ContentType="text/markdown")
        logger.info("Report with %s rows uploaded as %s", len(model["data"]), REPORT_FILE)
    finally:
        path.unlink(missing_ok=True)


@task(task_display_name="Notify")
def notify_report() -> None:
    send_notification(title="Midnight report", body=f"Nový report {REPORT_FILE} je pripravený.")


@dag(
    "midnight_report",
    dag_display_name="Midnight Report",
    description="Renders the weather dataset into a Markdown report every night.",
    schedule="5 0 * * *",
    start_date=pendulum.datetime(2026, 1, 1, tz="UTC"),
    tags=["weather", "devops", "report"],
    catchup=False,
)
def main():
    is_rustfs_alive() >> create_report() >> notify_report()


main()
```

**Ako odskúšané:** Airflow 3.3.2 cez `airflow standalone`, lokálna náhrada OpenWeatherMap (pre `nowhere` vracia 404), S3 cez moto a namiesto Pushbulletu lokálny server cez `json://` URL v Variable.

- Beh s Variable (`kosice,sk`, `presov,sk`): dve vetvy, dve notifikácie, dva riadky v `dataset.csv`, a pretože `publish_data` je mapovaný, dva behy `report_builder` (`asset_triggered__…`).
- Beh z formulára `["zilina,sk", "nowhere", "poprad,sk"]`: Žilina a Poprad spracované a notifikované, vetva `nowhere` zlyhala na 404, beh `failed`.
- `midnight_report`: v S3 vznikol `midnight-report.md` (`ContentType: text/markdown`) s tabuľkou všetkých riadkov a prišla notifikácia. Plánovaný beh, ktorý sa spustil skôr, ako existoval dataset, správne zlyhal s *Dataset file not found*.
- V dočasnom priečinku neostali žiadne súbory.

## Otestuj sa

<Question q="Čo je model, šablóna a render?">
Model sú dáta (napr. slovník), šablóna je text so zástupnými miestami a render ich spojí do výsledného textu.
</Question>

<Question q='Čo vráti `env.from_string("{{ name }} is {{ age }}").render()`?'>
`' is '` — chýbajúce hodnoty sa vyrenderujú ako prázdne reťazce.
</Question>

<Question q="Aký je rozdiel medzi `{{ … }}` a `{% … %}` v Jinja?">
`{{ … }}` vloží hodnotu výrazu. `{% … %}` je riadiaci príkaz — cyklus, podmienka, priradenie.
</Question>

<Question q="Na čo je mínus v `{% for entry in data -%}`?">
Odstráni biele znaky (aj nový riadok) za značkou, takže cyklus nenecháva vo výsledku prázdne riadky.
</Question>

<Question q="Čo robí `csv.DictReader` a čo potrebuje?">
Číta CSV a každý riadok vráti ako slovník; kľúče berie z hlavičky (prvého riadku), takže súbor ju musí mať. Oddeľovač nastavíš cez `delimiter`.
</Question>

<Question q="Ako nahráš do S3 reťazec bez ukladania do súboru?">
`bucket.put_object(Key="report.md", Body=report, ContentType="text/markdown")`.
</Question>

<Question q="Prečo `autoescape=False` pri Markdown reporte?">
Autoescape nahrádza znaky HTML (`<`, `>`, `&`) entitami — ochrana pre HTML stránky. V Markdown reporte by text zbytočne pokazil.
</Question>

## Cvičenia

### 21.1 · Počet meraní v reporte

Dopíš do šablóny pod tabuľku riadok *Spolu meraní: N* a do modelu nič nepridávaj.

<Solution>
```jinja
Spolu meraní: **{{ data | length }}**
```

`| length` je Jinja **filter** — upraví hodnotu pred vypísaním (tu dĺžka zoznamu). Ďalšie: `upper`, `round(1)`, `default("–")`…
</Solution>

### 21.2 · Iba posledné meranie každého mesta

Uprav `create_report`, aby model obsahoval len **posledný** záznam každého mesta (napr. pre report o aktuálnom počasí).

<Solution>
```python
latest = {}
with open(path, encoding="utf-8") as file:
    for row in csv.DictReader(file, delimiter=","):
        latest[row["name"]] = row          # later rows overwrite earlier ones
model["data"] = list(latest.values())
```

Kľúčom slovníka je mesto, takže každý ďalší riadok toho istého mesta prepíše predošlý — ostane posledný.
</Solution>
