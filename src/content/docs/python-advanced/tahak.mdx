## Spúšťanie a nástroje

<div class="sheet-grid">

```bash title="Spustenie skriptu"
python3 workflow.py
# alebo: 1. riadok #!/usr/bin/env python3
chmod +x workflow.py
./workflow.py
echo $?            # exit kód (0 = OK)
```

```bash title="ruff"
ruff check workflow.py    # linter
ruff format workflow.py   # formátovač
```

## Bash workflow: httpie + jq

<div class="sheet-grid">

```bash title="HTTP z terminálu"
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric

curl "https://api.openweathermap.org/data/2.5/weather?q=kosice,sk&appid=$APPID&units=metric"
```

```bash title="jq"
jq .                    # celý JSON pekne
jq .main.temp           # vnorený kľúč
jq '.dt, .name'         # viac hodnôt
jq -r '[.dt, .name] | @csv'
jq -r '.dt | todate'    # timestamp → ISO
... | tee -a dataset.csv  # pripoj + vypíš
```

```python title="HTTP a JSON"
import httpx

response = httpx.get(url, params={"q": "kosice"})
response.status_code   # 200
response.headers
response.text          # str
data = response.json() # dict
data["main"]["temp"]
data["weather"][0]["main"]
data.get("rain", 0)
```

```python title="Čas"
import pendulum

dt = pendulum.from_timestamp(1779196038)
dt.to_iso8601_string()  # '2026-05-19T13:07:18Z'
pendulum.now("Europe/Moscow")  # teraz v Moskve
dt.in_timezone("Europe/Bratislava")  # +02:00
# ukladaj v UTC, prevádzaj až pri zobrazení
```

## Užitočné drobnosti

| Čo | Ako |
| --- | --- |
| typ premennej | `type(var)` |
| info o premennej v ipythone | `var?` |
| HTTP stavové kódy | `2xx` OK · `3xx` presmerovanie · `4xx` chyba klienta · `5xx` chyba servera |
| exit status v Bashi | `echo $?` — `0` OK, inak chyba |
| dĺžka reťazca / zoznamu | `len(var)` |
| skladanie reťazcov | f-string: `f"{url}?q={query}"` |
| kľúč nie v kóde ani v argumentoch | `APPID=... ./workflow.py kosice` |
