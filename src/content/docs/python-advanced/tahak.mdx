## Bash workflow: httpie + jq

<div class="sheet-grid">

```bash title="HTTP z terminálu" wrap
http https://api.openweathermap.org/data/2.5/weather \
    q==kosice,sk appid==$APPID units==metric

curl "https://api.openweathermap.org/data/2.5/weather?q=kosice,sk&appid=$APPID&units=metric"
```

```bash title="jq" wrap
jq .                    # celý JSON pekne
jq .main.temp           # vnorený kľúč
jq '.dt, .name'         # viac hodnôt
jq -r '[.dt, .name] | @csv'
jq -r '.dt | todate'    # timestamp → ISO
... | tee -a dataset.csv  # pripoj + vypíš
```

## Apache Airflow

<div class="sheet-grid">

```bash title="Inštalácia a beh" wrap
pip install apache-airflow
airflow info                # vytvorí ~/airflow/airflow.cfg
export AIRFLOW_HOME=$(pwd)/airflow_home
airflow standalone          # všetko naraz, UI :8080
tmux attach                 # späť k sedeniu
sudo systemctl status airflow
```

```bash title="CLI" wrap
airflow dags list
airflow tasks list weather_scraper
airflow dags test weather_scraper
airflow dags trigger -l 2026-03-15 weather_scraper
airflow variables set weather_city poprad,sk
airflow variables get weather_city
airflow connections get openweathermap
```

```python title="DAG a tasky" wrap
from airflow.sdk import dag, task
from pendulum import datetime

@task
def scrape_data(query: str) -> dict: ...

@dag("weather_scraper", schedule="*/20 * * * *",
     start_date=datetime(2026, 1, 1),
     catchup=False, tags=["weather"])
def main(query: str = "kosice,sk"):
    data = scrape_data(query)
    is_service_alive() >> data

if __name__ == "__main__":
    main().test()
else:
    main()
```

```python title="Connections, Variables, chyby" wrap
from airflow.sdk import BaseHook, Variable
from airflow.sdk.exceptions import (
    AirflowException, AirflowFailException)

conn = BaseHook.get_connection("openweathermap")
conn.host; conn.port; conn.password
conn.extra_dejson.get("units")
Variable.get("weather_city", default="kosice,sk")
Variable.get("cfg", deserialize_json=True)

@task(retries=3, retry_delay=timedelta(seconds=30))
raise AirflowException("retry me")
raise AirflowFailException("no retry")
```

| Čo | Ako |
| --- | --- |
| cron | `min hod deň mesiac deň_v_týždni` · `*/20 * * * *` · `@hourly`, `@daily`, `@weekly`, `@monthly`, `@yearly` |
| config premennou prostredia | `AIRFLOW__CORE__LOAD_EXAMPLES=False` |
| Variable / Connection z prostredia | `AIRFLOW_VAR_WEATHER_CITY=…` · `AIRFLOW_CONN_OPENWEATHERMAP='{"conn_type": …}'` |
| stavy taskov | queued (sivá) · running · success (zelená) · failed (červená) · upstream_failed (oranžová) · up_for_retry (žltá) |
| `retries=3` | až 4 behy; `retry_delay` predvolene 300 s |
| súbor vedľa DAG-u | `Path(__file__).parent / "weather.schema.json"` |
| JSON schéma | `jsonschema.validate(instance=data, schema=schema)` |
| logovanie | `logger = logging.getLogger(__name__)` · DEBUG < INFO < WARNING < ERROR < CRITICAL |
| swap | `fallocate -l 2G /swapfile` → `chmod 600` → `mkswap` → `swapon` · `free -h` |
| tmux (prefix `Ctrl+b`) | `c` nové okno · `n`/`p` ďalšie/predošlé · `"`/`%` rozdeliť · `d` odpojiť · `tmux attach` |

## Užitočné drobnosti

| Čo | Ako |
| --- | --- |
| typ premennej | `type(var)` |
| info o premennej v ipythone | `var?` |
| HTTP stavové kódy | `2xx` OK · `3xx` presmerovanie · `4xx` chyba klienta · `5xx` chyba servera |
| exit status v Bashi | `echo $?` — `0` OK, inak chyba |
| dĺžka reťazca / zoznamu | `len(var)` |
| skladanie reťazcov | f-string: `f"{url}?q={query}"` |
| kľúč nie v kóde ani v argumentoch | `APPID=... ./workflow.py kosice` |
