<KeyPoints>
- `while` = opakuj, **kým** platí podmienka. `for` = prejdi **každý prvok** postupnosti.
- `range(start, stop, step)` **nezahŕňa** `stop`: `range(1, 4)` → `1, 2, 3`.
- Každý `while` musí mať cestu k ukončeniu, inak vznikne nekonečný cyklus (zastavíš ho `Ctrl+C`).
- `break` cyklus ukončí, `continue` preskočí na ďalšiu iteráciu.
- Vnorený cyklus sa vykoná **celý** pri každej iterácii vonkajšieho.
</KeyPoints>

## Dva druhy cyklov

Cyklus opakuje blok kódu bez toho, aby sme ten istý príkaz písali viackrát. Jedno vykonanie tela cyklu sa volá **iterácia**.

| Situácia | Voľba |
| --- | --- |
| „Opakuj päťkrát“ | `for` + `range(5)` |
| „Pre každý produkt v zozname“ | `for` |
| „Kým používateľ nezadá správnu hodnotu“ | `while` |
| „Čítaj hodnoty až po slovo `koniec`“ | `while` so sentinelom |

## Cyklus `while`

`while` sa hodí, keď vopred nepoznáme počet opakovaní. Podmienka sa kontroluje **pred** každou iteráciou.

```python title="countdown.py"
seconds = 5

while seconds > 0:
    print(seconds)
    seconds -= 1

print("Štart!")
```

Premenná `seconds` sa musí meniť. Bez riadka `seconds -= 1` by podmienka zostala navždy pravdivá a vznikol by **nekonečný cyklus**.

:::tip[Ako zastaviť zaseknutý program]
V termináli stlač `Ctrl+C`. Potom nájdi hodnotu, ktorá rozhoduje o ukončení, a over, či sa v každej vetve naozaj mení.
:::

### Validácia vstupu

Cyklus vie používateľa opakovane vyzvať, kým nezadá platnú hodnotu.

```python title="validation.py"
age = int(input("Zadaj vek od 0 do 120: "))

while age < 0 or age > 120:
    print("Neplatná hodnota.")
    age = int(input("Zadaj vek od 0 do 120: "))

print(f"Uložený vek: {age}")
```

Tento príklad ešte nerieši text namiesto čísla — to doplníme v kapitole [Súbory a chyby](/devops-notes/python/subory-a-chyby/#bezpečný-číselný-vstup).

### Sentinel

**Sentinel** je špeciálna hodnota, ktorá znamená „koniec vstupu“. Nesmie sa dať pomýliť s platnou hodnotou.

```python title="average.py"
total = 0.0
count = 0

value = float(input("Suma objednávky (-1 = koniec): "))

while value != -1:
    total += value
    count += 1
    value = float(input("Suma objednávky (-1 = koniec): "))

if count > 0:
    print(f"Priemer: {total / count:.2f} €")
else:
    print("Nebola zadaná žiadna objednávka.")
```

- `total` je **akumulátor** — zbiera súčet.
- `count` je **počítadlo** — počíta iterácie.
- `total += value` je skrátený zápis pre `total = total + value`.

## Cyklus `for`

`for` sa hodí, keď prechádzame kolekciu alebo poznáme počet opakovaní.

```python
topics = ["premenné", "podmienky", "cykly"]

for topic in topics:
    print(f"Študujem: {topic}")
```

Premenná `topic` postupne dostane každú hodnotu zo zoznamu.

### `range()` bez hádania

`range(start, stop, step)` vytvorí postupnosť celých čísel. Hodnota `stop` sa **nezahŕňa**.

| Zápis | Vygenerované hodnoty |
| --- | --- |
| `range(5)` | `0, 1, 2, 3, 4` |
| `range(2, 5)` | `2, 3, 4` |
| `range(2, 10, 3)` | `2, 5, 8` |
| `range(5, 0, -1)` | `5, 4, 3, 2, 1` |

```python
for number in range(1, 6):
    print(number)  # 1, 2, 3, 4, 5

for even in range(0, 11, 2):
    print(even)    # 0, 2, 4, 6, 8, 10
```

## `break` a `continue`

- `break` okamžite **ukončí** celý cyklus.
- `continue` preskočí zvyšok tela a pokračuje **ďalšou iteráciou**.

```python title="break_continue.py"
while True:
    command = input("Príkaz (koniec = stop): ").strip()

    if command == "":
        continue          # prázdny vstup ignoruj, pýtaj sa znova
    if command == "koniec":
        break             # opusti cyklus

    print(f"Vykonávam: {command}")

print("Program skončil.")
```

Vzor `while True` + `break` je bežný, keď sa o ukončení rozhoduje až uprostred tela cyklu.

## Vnorené cykly

Vnútorný cyklus sa dokončí pri **každej** iterácii vonkajšieho. Takto spracuješ tabuľku, maticu alebo kombinácie hodnôt.

```python title="schedule.py"
for day in range(1, 4):
    print(f"Deň {day}")

    for lesson in range(1, 3):
        print(f"  Lekcia {lesson}")
```

Výsledkom je šesť lekcií: dve pre každý z troch dní.

## Kompletný príklad: tri objednávky

```python title="orders.py" {8-10}
grand_total = 0.0

for order_number in range(1, 4):
    print(f"\nObjednávka {order_number}")
    item_count = int(input("Počet položiek: "))
    order_total = 0.0

    for item_number in range(1, item_count + 1):
        price = float(input(f"Cena položky {item_number}: "))
        order_total += price

    grand_total += order_total
    print(f"Suma objednávky: {order_total:.2f} €")

print(f"\nCelkový obrat: {grand_total:.2f} €")
```

## Otestuj sa

<Question q="Aké hodnoty vygeneruje `range(2, 10, 3)`?">
`2, 5, 8`. Začne na `2`, pripočítava `3` a skončí pred `10`.
</Question>

<Question q="Aký je rozdiel medzi `break` a `continue`?">
`break` ukončí celý cyklus. `continue` preskočí iba zvyšok aktuálnej iterácie a cyklus pokračuje ďalšou.
</Question>

<Question q="Koľkokrát sa vykoná `print()` v `for i in range(3):` → `for j in range(4):` → `print(i, j)`?">
12-krát. Vnútorný cyklus (4 iterácie) sa vykoná celý pre každú zo 3 iterácií vonkajšieho: 3 × 4 = 12.
</Question>

<Question q="Čo je sentinel a akú hodnotu by nemal mať?">
Špeciálna hodnota, ktorá ukončí zadávanie (napr. `-1` alebo `"koniec"`). Nesmie to byť hodnota, ktorú by používateľ mohol zadať ako platné dáta.
</Question>

<Question q="Prečo sa tento cyklus nikdy neskončí? `i = 0` → `while i < 5:` → `print(i)`">
Premenná `i` sa v tele nemení, takže `i < 5` zostane navždy pravdivé. Chýba `i += 1`.
</Question>

## Cvičenia

### 3.1 · Súčet až po sentinel

Opakovane načítavaj čísla. Hodnota `-1` ukončí vstup a do súčtu sa **nezapočíta**. Na konci vypíš počet hodnôt, súčet a priemer. Ošetri situáciu, keď používateľ nezadá ani jednu hodnotu.

<p class="practises">Precvičíš: `while`, sentinel, akumulátor, `break`, delenie nulou.</p>

<Solution>
```python title="sucet.py"
total = 0.0
count = 0

while True:
    value = float(input("Číslo (-1 = koniec): "))
    if value == -1:
        break

    total += value
    count += 1

print(f"Počet hodnôt: {count}")
print(f"Súčet: {total:g}")

if count > 0:
    print(f"Priemer: {total / count:g}")
else:
    print("Priemer nemožno vypočítať — nebola zadaná žiadna hodnota.")
```

Formát `:g` vypíše číslo bez zbytočných núl (`7.0` → `7`).
</Solution>

### 3.2 · Násobilka

Pomocou vnorených cyklov vypíš tabuľku násobenia od 1 do 10. Stĺpce zarovnaj.

```text title="Skrátený náhľad"
  1   2   3   4   5
  2   4   6   8  10
  3   6   9  12  15
```

<p class="practises">Precvičíš: vnorené `for`, `range`, `print(..., end="")`.</p>

<Solution variant="hint">
Vo f-stringu zadáš minimálnu šírku zarovnanú doprava: `f"{value:>4}"`. Aby `print()` neodriadkoval, použi `end=""`.
</Solution>

<Solution>
```python title="nasobilka.py"
SIZE = 10

print("    ", end="")
for column in range(1, SIZE + 1):
    print(f"{column:>4}", end="")
print()
print("    " + "────" * SIZE)

for row in range(1, SIZE + 1):
    print(f"{row:>2} │", end="")
    for column in range(1, SIZE + 1):
        print(f"{row * column:>4}", end="")
    print()
```
</Solution>
