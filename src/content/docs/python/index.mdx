## Postup pri riešení úlohy

1. **Vstup → spracovanie → výstup.** Najprv si napíš, aké údaje program dostane, čo s nimi urobí a čo vypíše.
2. **Odhadni výsledok** pred spustením. Ak sa líši, hľadaj prečo — tam sa učíš najviac.
3. **Otestuj hraničné hodnoty:** presne `0`, `15`, `18`, prázdny vstup, text namiesto čísla.

Kontrolný zoznam pred odovzdaním:

- Program sa spustí bez syntaktickej chyby.
- Názvy premenných a funkcií hovoria, čo obsahujú alebo robia.
- Každý cyklus má jasnú podmienku ukončenia.
- Chybový stav vypíše zrozumiteľnú správu, nie traceback.
- Opakovaná logika je presunutá do funkcie.
