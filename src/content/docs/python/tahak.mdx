## Typy, vstup a výstup

<div class="sheet-grid">

```python title="Typy a konverzie"
type(42)          # <class 'int'>
int("42")         # 42
float("3.5")      # 3.5
str(42)           # '42'
int("3.5")        # ValueError
int(3.9)          # 3 (oreže)
round(3.567, 2)   # 3.57
bool("")          # False
```

```python title="Vstup a výstup"
name = input("Meno: ")      # vždy str
age = int(input("Vek: "))

print("a", "b", sep="-", end="!\n")

print(f"{19.9:.2f} €")      # 19.90 €
print(f"{7:03}")            # 007
print(f"{'ab':>5}")         # '   ab'
```

```python title="Funkcie"
def total(price, qty, discount=0.0):
    """Default parametre až na konci."""
    return price * qty * (1 - discount)

total(10, 3, discount=0.1) # pomenovane

def minmax(xs):
    return min(xs), max(xs)  # n-tica
```

## Pasce na skúške

| Pasca | Správne |
| --- | --- |
| `input()` vracia text, `"5" + 1` je `TypeError` | `int(input())` |
| `range(1, 5)` končí na `4` | `range(1, 6)` pre 1–5 |
| `if x = 5:` | `if x == 5:` |
| `elif` s miernejšou podmienkou navrch | najprísnejšia podmienka prvá |
| `xs = xs.sort()` → `None` | `xs.sort()` alebo `xs = sorted(xs)` |
| `b = a` a potom zmena `b` mení aj `a` | `b = a.copy()` |
| `name.upper()` bez priradenia nič nezmení | `name = name.upper()` |
| funkcia s `print` namiesto `return` vráti `None` | `return výsledok` |
| `def f(a=1, b):` | default parametre na koniec |
| `def f(items=[])` — zoznam sa zdieľa medzi volaniami | `items=None`, vo funkcii `if items is None: items = []` |
| `{}` je prázdny slovník | prázdna množina je `set()` |
| `open(..., "w")` vymaže súbor | `"a"` na pridávanie |
| holé `except:` | `except ValueError:` |
| `0.1 + 0.2 == 0.3` je `False` | `round(...)` alebo `math.isclose()` |
