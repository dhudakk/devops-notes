Python program je postupnosť presných inštrukcií. Pri návrhu je užitočné rozdeliť problém na tri časti:

1. **Vstup** — aké údaje program potrebuje?
2. **Spracovanie** — aké výpočty alebo rozhodnutia nad nimi vykoná?
3. **Výstup** — aký výsledok má používateľ dostať?

Tomuto modelu sa hovorí **IPO** (*Input–Process–Output*). Pred písaním kódu si riešenie môžeme zapísať ako pseudokód alebo nakresliť ako vývojový diagram.

## Prvý výstup

Funkcia `print()` vypíše hodnotu do konzoly. Textový údaj — `str` — zapisujeme do úvodzoviek.

```python title="hello.py"
print("Ahoj, Python!")
print('Jednoduché aj dvojité úvodzovky sú platné.')
```

Znak `#` začína komentár. Python ho pri vykonávaní preskočí.

```python
# Toto vysvetľuje zámer nasledujúceho riadka.
print("Objednávkový systém")  # krátky komentár môže byť aj na konci
```

:::tip
Komentár má vysvetľovať **prečo**, nie mechanicky opakovať, čo kód robí.
:::

## Premenné a pomenovanie

Premenná je meno odkazujúce na hodnotu. Python má dynamické typovanie: typ patrí hodnote a môže sa počas behu zmeniť. V praxi však nemeníme význam premennej bez dobrého dôvodu.

```python
product_name = "Mechanická klávesnica"
quantity = 2
unit_price = 89.90
is_available = True
```

Dobré názvy sú malé, popisné a slová oddeľujú podčiarkovníkom (`snake_case`). Python rozlišuje veľké a malé písmená: `price` a `Price` sú dve rôzne mená.

Konštanta nie je v Pythone technicky uzamknutá. Veľké písmená sú dohoda, ktorá hovorí: „túto hodnotu nemeň“.

```python
VAT_RATE = 0.20
ADMIN_FEE = 2.50
```

## Základné dátové typy

| Typ | Význam | Príklad |
| --- | --- | --- |
| `str` | text | `"Python"` |
| `int` | celé číslo | `42` |
| `float` | desatinné číslo | `19.90` |
| `bool` | pravda/nepravda | `True`, `False` |
| `None` | chýbajúca/žiadna hodnota | `None` |

Typ hodnoty overíme pomocou `type()`:

```python
lesson_count = 8
print(type(lesson_count))  # <class 'int'>
```

## Vstup od používateľa

`input()` vždy vráti reťazec — aj keď používateľ napíše číslo. Ak chceme počítať, hodnotu musíme skonvertovať.

```python title="order.py"
product = input("Názov produktu: ")
quantity = int(input("Počet kusov: "))
unit_price = float(input("Cena za kus: "))

subtotal = quantity * unit_price
print(f"{product}: {subtotal:.2f} €")
```

F-string vloží hodnoty priamo do textu. Zápis `:.2f` zobrazí desatinné číslo na dve miesta.

:::caution[Čo ak používateľ zadá „dva“?]
`int("dva")` vyvolá `ValueError`. Neskôr ho ošetríme pomocou `try`/`except`; na začiatku aspoň zadanie formulujme jasne.
:::

## Aritmetické operátory

```python
a = 17
b = 5

print(a + b)   # 22   sčítanie
print(a - b)   # 12   odčítanie
print(a * b)   # 85   násobenie
print(a / b)   # 3.4  klasické delenie
print(a // b)  # 3    celočíselné delenie
print(a % b)   # 2    zvyšok po delení
print(a ** b)  # 141985 umocnenie
```

Prednosť operácií je podobná matematike: zátvorky, mocniny, násobenie/delenie a nakoniec sčítanie/odčítanie. Keď by výraz mohol byť nejasný, použi zátvorky.

```python
total = (unit_price * quantity) + ADMIN_FEE
```

## Formátovanie výstupu

`print()` oddeľuje argumenty medzerou a končí novým riadkom. Parametre `sep` a `end` to menia.

```python
print("2026", "09", "12", sep="-")     # 2026-09-12
print("Načítavam", end="... ")
print("hotovo")                           # Načítavam... hotovo
```

Únikové sekvencie reprezentujú špeciálne znaky:

```python
print("Prvý riadok\nDruhý riadok")
print("Názov:\tPython")
print("Povedal: \"Ahoj\"")
print("C:\\Users\\student")
```

## Kompletný príklad: objednávka

```python title="objednavka.py" {8-10}
ADMIN_FEE = 2.50

customer = input("Meno zákazníka: ")
product = input("Produkt: ")
quantity = int(input("Počet kusov: "))
unit_price = float(input("Cena za kus (€): "))

subtotal = quantity * unit_price
total = subtotal + ADMIN_FEE

print("\n--- Súhrn objednávky ---")
print(f"Zákazník: {customer}")
print(f"Položka: {quantity}× {product}")
print(f"Medzisúčet: {subtotal:.2f} €")
print(f"Administratívny poplatok: {ADMIN_FEE:.2f} €")
print(f"Spolu: {total:.2f} €")
```

:::note[Peniaze v reálnej aplikácii]
`float` je vhodný na výučbu, ale nie vždy presne reprezentuje desatinné hodnoty. Produkčný finančný systém používa napríklad `decimal.Decimal` alebo sumy uložené v centoch.
:::
