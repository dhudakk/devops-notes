Zoznam (`list`) uchováva usporiadanú kolekciu hodnôt a môžeme ho meniť. N-tica (`tuple`) je tiež usporiadaná, ale po vytvorení je nemenná.

```python
topics = ["Python", "Git", "Terraform"]
coordinates = (48.1486, 17.1077)
```

## Indexy a rezy

Indexovanie začína nulou. Záporný index počíta od konca.

```python
topics = ["Python", "Git", "Terraform", "Kubernetes"]

print(topics[0])      # Python
print(topics[-1])     # Kubernetes
print(topics[1:3])    # ['Git', 'Terraform']
print(topics[:2])     # ['Python', 'Git']
```

Rovnako ako pri `range()`, pravá hranica rezu sa nezahŕňa.

## Úprava zoznamu

```python title="list_operations.py"
participants = ["Eva", "Marek"]

participants.append("Zuzana")
participants.insert(1, "Adam")
participants.remove("Marek")
last_added = participants.pop()

print(participants)  # ['Eva', 'Adam']
print(last_added)    # Zuzana
```

Užitočné operácie:

| Zápis | Výsledok |
| --- | --- |
| `len(items)` | počet prvkov |
| `value in items` | test prítomnosti |
| `items.sort()` | zoradí pôvodný zoznam |
| `sorted(items)` | vráti nový zoradený zoznam |
| `items.count(x)` | počet výskytov `x` |

## Pozor na zdieľaný zoznam

Priradenie nevytvorí kópiu. Obe mená budú odkazovať na ten istý objekt.

```python
original = [1, 2, 3]
alias = original
copy = original.copy()

alias.append(4)

print(original)  # [1, 2, 3, 4]
print(copy)      # [1, 2, 3]
```

Pre plochý zoznam stačí `.copy()` alebo rez `[:]`. Pri vnorených meniteľných objektoch môže byť potrebný `copy.deepcopy()`.

## Prechádzanie zoznamu

```python
prices = [12.50, 8.90, 25.00]
total = 0.0

for price in prices:
    total += price

print(f"Spolu: {total:.2f} €")
```

Ak potrebujeme hodnotu aj index, použijeme `enumerate()`.

```python
for position, topic in enumerate(topics, start=1):
    print(f"{position}. {topic}")
```

## Vnorené zoznamy

Tabuľku možno reprezentovať ako zoznam riadkov.

```python title="matrix.py"
attendance = [
    [True, True, False],
    [True, False, True],
]

for student_number, days in enumerate(attendance, start=1):
    attended = sum(days)  # True sa pri sčítaní správa ako 1
    print(f"Študent {student_number}: {attended} dni")
```

## Kedy použiť n-ticu

N-tica sa hodí pre pevne danú skupinu hodnôt — napríklad RGB farbu, súradnice alebo viac výsledkov funkcie.

```python
primary_color = (76, 224, 179)
latitude, longitude = (48.1486, 17.1077)
```

Nemennosť neznamená absolútnu ochranu: ak n-tica obsahuje zoznam, samotný vnorený zoznam stále môžeme meniť.

## Zapamätaj si

- `list` je meniteľný, `tuple` nie.
- Prvý prvok má index `0`, posledný `-1`.
- Pravá hranica rezu sa nezahŕňa.
- `alias = original` nevytvára kópiu.
